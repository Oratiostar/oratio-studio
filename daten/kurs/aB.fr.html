Terme Signification
Alias Nom court pour une longue commande, enregistré dans ~/.bashrc
apt Gestionnaire de paquets de Debian et de Raspberry Pi OS
Démarrage automatique Programmes qui démarrent automatiquement à la connexion (~/.config/autostart, ~/.config/labwc/autostart)
Débit en bauds Vitesse de transmission d'une liaison série, par exemple 9600 ou 115200
Bibliothèque (Library) Code tout fait pour un composant ou une tâche
Bootloader Petit programme de démarrage dans l'Arduino, qui permet le téléversement
Compilateur Transforme le code source en programme exécutable
Contrôleur (écran) Puce dans l'écran, par exemple SSD1306, ST7735S, GC9A01
cron Planificateur de tâches sous Linux
Système de fichiers Structure avec laquelle un disque gère les fichiers (ext4, exFAT, FAT32, NTFS)
Desktop Entry Fichier .desktop qui décrit un programme
ESP32 / ESP32-S3 Microcontrôleur avec WLAN et Bluetooth
FQBN Nom complet de la carte dans arduino-cli, par exemple arduino:avr:nano
GPIO Entrées/sorties librement programmables
GPT / MBR Types de table de partitions (GPT est moderne)
HDMI-A-1 Nom de la première sortie HDMI sous Wayland
Branchement à chaud (Hotplug) Un appareil est branché ou retiré en cours de fonctionnement
HUB75 Standard de raccordement pour panneaux de matrices de LED
I²C Bus à deux lignes (SDA, SCL), les appareils ont des adresses
JSON Format texte pour données structurées et réglages
Kanshi Programme qui applique des profils d'écran lors d'un changement de moniteur
labwc Gestionnaire de fenêtres de Raspberry Pi OS (Trixie) sous Wayland
LVGL Bibliothèque graphique pour écrans de microcontrôleurs
Mount / Montage Rendre un disque disponible dans un dossier
nano Éditeur de texte simple dans le terminal
NTP Protocole avec lequel un appareil récupère l'heure depuis Internet
NVMe Interface SSD rapide via PCIe (sur le Pi 5)
OLED Écran où chaque pixel s'allume lui-même
Partition Section d'un disque
PIO Entrée/sortie programmable de la puce Pico (pour HUB75)
PlatformIO Environnement de développement (dans VS Code) pour microcontrôleurs
Pipe (barre verticale) Transmet la sortie d'une commande à la suivante
PWM Modulation de largeur d'impulsion, règle par exemple la vitesse d'un ventilateur ou la luminosité
PyQt5 Bibliothèque Python pour fenêtres et interfaces
RTC Horloge temps réel (par exemple DS3231), garde l'heure sans courant
root Utilisateur administrateur sous Linux
Scale Facteur d'échelle de l'interface (1, 2, 3)
Moniteur série Fenêtre de l'environnement de développement pour les sorties texte du microcontrôleur
Shebang Première ligne #!/bin/bash, indique avec quoi un script s'exécute
Sketch Programme Arduino (.ino)
SPI Bus rapide à quatre lignes (MOSI, MISO, SCK, CS)
sudo Exécuter une commande avec les droits d'administrateur
systemd Gestion des services sous Linux
UART Liaison série simple (TX, RX)
UUID Identifiant unique d'un disque
Watchdog Programme qui vérifie en permanence si tout va bien et le corrige
Wayland / X11 Deux systèmes graphiques sous Linux
wlr-randr Réglages d'écran sous Wayland
