27.2 Dual Boot: SteamOS und Windows

Was passiert ist

  1. Windows wird auf einer vorbereiteten Partition installiert und startet, aber SteamOS ist danach nicht mehr erreichbar.
  2. Selbst mit der Tastenkombination fürs Startmenü startete SteamOS nicht. Es musste neu installiert werden, und Windows ging dabei verloren.
  3. Zwischendurch landete das Gerät im GRUB-Befehlsmodus (ein Bildschirm mit grub>).

Ursache

Beim Installieren schreibt Windows seinen eigenen Bootloader in die EFI-Partition und stellt sich in der Startreihenfolge nach vorn. Der Eintrag von SteamOS wird dabei überschrieben oder in der Boot-Reihenfolge verdrängt. Muss SteamOS jedes Mal neu installiert werden, geht das Problem tiefer als der Bootloader: Die SteamOS-Partition oder die Partitionstabelle wird beschädigt oder überschrieben.

Hilfsmittel und Begriffe

Begriff Bedeutung
EFI-Partition Kleine Partition mit den Startdateien aller Systeme
GPT Moderne Partitionstabelle
Free space before Freier Platz vor (links von) der Partition. Im Partitionswerkzeug wichtig, um nicht die falsche Seite zu verkleinern
GRUB Bootloader, den Linux-Systeme nutzen
rEFInd Grafischer Bootmanager, der alle installierten Systeme erkennt und zur Auswahl zeigt
Clover Bootmanager, der vor allem im Hackintosh-Bereich verbreitet ist. rEFInd gilt als einfacher und universeller
Windows To Go Windows läuft direkt von einem USB-Stick, ohne Festinstallation. Rufus bietet die Option an

Erste Hilfe bei grub>

exit

Das versucht, zurück ins Boot-Menü zu kommen. Hilft das nicht, braucht man die Reparatur über einen Bootstick.

rEFInd entfernen

Der Weg hängt vom System ab. Unter Linux löscht man den rEFInd-Ordner aus der EFI-Partition und den Eintrag aus der Boot-Liste (efibootmgr). Unter Windows geht es mit bcdedit und dem Löschen des Ordners. Die Mac-Methode gilt nicht für das Steam Deck.

Windows ohne Product Key, Hash prüfen

Zum Installieren gehört die Prüfung des Downloads: Get-FileHash (PowerShell) oder sha256sum (Linux) vergleichen mit dem Wert auf der Webseite (Kapitel 25.7). Eine Aktivierung ist nicht sofort nötig, Windows läuft auch eingeschränkt.

27.3 Windows 11 24H2 und der Dual Boot

Beobachtung: Das Update 24H2 verursacht bei Dual Boot mit SteamOS häufig Probleme (SteamOS startet nicht mehr, schwarzer Bildschirm beim Wechsel). Darum bleibt man besser bei Windows 11 23H2.

Frage: Wird 23H2 durch „Nach Updates suchen" automatisch auf 24H2 gehoben? Nicht automatisch durch einen Klick auf die Treiber-Updates, aber Microsoft schiebt große Funktionsupdates mit der Zeit nach. Man kann das verhindern, zum Beispiel mit der Einstellung für die Zielversion der Funktionsupdates in den Windows-Update-Optionen.

Merke: Vor jedem großen Windows-Update bei Dual Boot ein Backup der EFI-Partition und der SteamOS-Partition machen.

27.4 SteamOS, Bazzite und Batocera

  • SteamOS wird von Valve für das Steam Deck entwickelt.
  • Bazzite ist ein Spiele-System auf Fedora-Basis, das dem SteamOS ähnlich ist, aber auch auf anderen Geräten läuft.
  • Batocera ist ein reines Retro-Spiele-System (Kapitel 26).

27.5 Python: Raspberry Pi gegen Steam Deck

Zum Python-Lernen ist der Raspberry Pi in den meisten Fällen die bessere Wahl. Gründe: Er ist zum Lernen gebaut, läuft mit Linux, es gibt viele Tutorials, und man kann später LEDs, Sensoren und Motoren anschließen.

Wichtig: Der Satz „Python ist auf dem Pi schon installiert" stimmt für Raspberry Pi OS (dort ist Python 3 dabei). Auf dem Steam Deck (SteamOS) ist Python ebenfalls in der Systemgrundlage vorhanden, aber SteamOS ist ein schreibgeschütztes System. Zusatzpakete installiert man dort in einer eigenen Umgebung (python3 -m venv, Kapitel 3) oder über Flatpak.

27.6 Der „Einschränkungs"-Fund: Imager als AppImage

Es gibt eine Falle, die auf dem Steam Deck nicht auftritt, auf dem Raspberry Pi aber schon:

Ein Flash-Programm als AppImage (zum Beispiel der Imager) läuft auf dem Steam Deck (x86-64) nach chmod +x direkt. Auf dem Pi 5 (ARM64) kommt die Meldung Exec format error, weil die Datei für die falsche Prozessorarchitektur gebaut ist.

Gerät Prozessor AppImage für amd64
Steam Deck x86-64 (amd64) läuft
Raspberry Pi 5 ARM64 (aarch64) Exec format error

Lösung auf dem Pi: das passende Programm aus der Paketquelle installieren:

sudo apt update
sudo apt install rpi-imager
rpi-imager

Das ist der richtige Weg, weil Etcher offiziell vor allem für x86-64 angeboten wird.
