40.2 Qu’est-ce qui est resté identique ?

  1. Qt comme base (PyQt5) : fenêtres, mises en page, signaux, dessin.
  2. Les scripts sont lancés avec subprocess ; les programmes de terminal avec lxterminal -e.
  3. Les tuiles sont dans un fichier JSON (oratio_apps.json). Seul le format est devenu plus riche.
  4. La décision sur les droits d'accès du chapitre 32.5 : la fenêtre tourne sans sudo.
  5. Les réglages sont enregistrés dans des fichiers JSON à côté du programme, pas dans le registre, pas dans une base de données.
  6. Kanshi pour la résolution de l'écran (chapitre 33) : le programme réécrit la configuration et relance kanshi.
  7. Les appareils (LED, ventilateur, OLED, PS5) gardent leurs services et leur propre fichier de réglages.

40.4 Avantages et inconvénients

Projet A

Avantages

  • On comprend chaque ligne. Chaque bouton est un QPushButton, chaque action un subprocess.
  • Rapide à modifier : un nouvel onglet, c'est dix lignes.
  • Tourne sur n'importe quel Pi sans paquets supplémentaires en dehors de PyQt5.
  • Bon pour apprendre : toutes les méthodes (onglets, mises en page, signaux, processus, JSON) apparaissent une par une.

Inconvénients

  • Une erreur de syntaxe, une mauvaise indentation ou un fichier manquant arrête tout.
  • L'apparence dépend de chaque bouton ; elle devient vite disparate.
  • Le glisser à la souris maison est lourd et fragile (chapitre 34).
  • Pas de pages, pas de tailles, pas de widgets : l'écran est plein après 20 tuiles.

Projet B

Avantages

  • Un onglet cassé, un widget défectueux, un fichier de langue manquant : le reste fonctionne.
  • Apparence homogène, parce que tout est dessiné par la même boîte à outils.
  • Grandit sans devenir confus (des dossiers au lieu d'un fichier géant).
  • Presque tout se règle depuis la fenêtre ; peu de choses sont à modifier dans des fichiers.

Inconvénients

  • Très grand : un débutant ne s'y retrouve plus dans 100 fichiers.
  • Une nouvelle idée touche souvent plusieurs fichiers (vue, fenêtre, recherche, liste de réglages).
  • Plus de dépendances (Vosk, Piper, Ollama, grim, wlrctl, nmcli) et plus de choses qui peuvent défaillir sur un autre matériel.
  • Le verre dessiné soi-même coûte du CPU : sur le Pi 5 en 4K, il faut économiser les effets (chapitre 37.7).
  • Une partie n'a pas été testée sur du vrai matériel (clone de sauvegarde, point d'accès, caméra, audio) ; c'est précisé à chaque fois dans le chapitre.
