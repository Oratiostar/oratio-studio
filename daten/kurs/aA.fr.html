Ce répertoire contient les commandes du cours, classées par thème (A.1), comme index de A à Z (A.2) et les appels de ses propres programmes (A.3). Les exemples sont de vraies lignes tirées de projets, en partie abrégées.

A.1 Par thèmes

Fichiers

cat – afficher le contenu d'un fichier dans le terminal. Bon pour vérifier de petits fichiers de configuration.

cat /home/oratio/Oratio_Control_Center/ANLEITUNG.txt
cat ~/Desktop/FNK0113.desktop ~/Desktop/pi-apps.desktop
cat ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json

cd – changer de dossier. cd .. remonte d'un niveau, cd ~ va dans le dossier personnel.

cd ~/Desktop/RGB-Matrix-Px-xx/example/Rasberry-Pi/bindings/python/samples
cd ~/Desktop/RGB-Matrix-Px-xx/example/Raspberry-Pi/bindings/python/samples
cd /home/oratio/Desktop/RGB-Matrix-Px-xx/example/Rasberry-Pi/examples-api-use

cp – copier des fichiers. Avec -r aussi des dossiers.
Options : -r récursif

sudo cp /boot/firmware/cmdline.txt.backup /boot/firmware/cmdline.txt
cp -r ~/Freenove_Tower_Cooler_for_Raspberry_Pi/* ~/Oratio_Control_Center/
cp /pfad/zur/datei /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/

du – afficher l'espace occupé par les dossiers.
Options : -h tailles lisibles, -s seulement le total

du -ah / | sort -hr | head -20
du -sh ~/Freenove_Tower_Cooler_for_Raspberry_Pi
sudo du -xh / --max-depth=1 2>/dev/null | sort -h

echo – afficher du texte. Avec >>, ajouter à un fichier.

echo "Scale wird gesetzt auf: $SCALE"
echo 'export PICO_SDK_PATH=$HOME/pico-sdk' >> ~/.bashrc
echo "alias fhd='wlr-randr --output HDMI-A-1 --mode 1920x1080'" >> ~/.bashrc

head – montrer les premières lignes d'un fichier ou d'une sortie.
Options : -n 20

head -100 app_ui.py
head -150 app_ui.py
head -20 app_ui_pi_tools.py

ln – créer un lien entre fichiers.
Options : -s lien symbolique

ln -s /home/oratio/Oratio_Control_Center \

ls – lister fichiers et dossiers.
Options : -l détails et droits, -a aussi les cachés, -d seulement le dossier lui-même

ls -l ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json
ls -l /home/oratio/Oratio_Control_Center/Code/picture/xpm/FNK0113.xpm
ls -l /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json

mkdir – créer un dossier.
Options : -p crée aussi les dossiers intermédiaires manquants

mkdir -p ~/Dokumente/PlatformIO/Projects/PicoTest
mkdir -p ~/Dokumente/PlatformIO/Projects/TestPico
sudo mkdir -p /mnt/nvme && sudo mount /dev/nvme0n1p1 /mnt/nvme

mv – déplacer ou renommer des fichiers.

mv Freenove_Tower_Cooler_for_Raspberry_Pi Oratio_Control_Center
mv Freenove_Tower_Cooler_for_Raspberry_Pi "Horacio_Control_Center"
mv Freenove_Tower_Cooler_for_Raspberry_Pi "Oratio_Kontrollzentrum"

nano – éditeur de texte dans le terminal. Enregistrer Ctrl+O, Entrée ; quitter Ctrl+X.

nano ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_ui_oled.py
sudo nano ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json
nano /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/task_oled.py

rm – supprimer des fichiers. Définitif, pas de corbeille !
Options : -r dossier, -f sans demande (dangereux)

rm /mnt/ssd/fio-testfile /mnt/ssd/test.txt
rm -rf ~/Freenove_Tower_Cooler_for_Raspberry_Pi
rm -rf ~/.platformio/packages/toolchain-gccarmnoneeabi*

tail – montrer les dernières lignes.
Options : -f suivre en direct

tail -f app.log
tail -20 api_service.py
tail -100 /home/oratio/Oratio_Control_Center/app_ui_menu.py

tar – créer et extraire des archives (.tar, .tar.gz).
Options : -xzf extraire, -czf créer

tar -xzvf backup.tar.gz
tar -xf pycharm-*.tar.gz
tar -czvf backup.tar.gz Dokumente

touch – créer un fichier vide ou renouveler l'horodatage.

touch test.txt
touch app_ui_scripts.py
touch /mnt/ssd/test.txt && ls -l /mnt/ssd/test.txt

unzip – extraire des archives ZIP.

unzip backup.zip

pwd – affiche le dossier courant.

Droits

chmod – changer les droits d'un fichier. chmod +x datei rend un fichier exécutable.
Options : +x exécutable

chmod +x ~/.local/share/applications/FNK0113.desktop
chmod -R 755 /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi
chmod -R u+rw /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi

chown – changer le propriétaire d'un fichier ou d'un dossier.
Options : -R aussi les sous-dossiers

sudo chown oratio:oratio app_config.json
sudo chown -R oratio:oratio /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi
sudo chown oratio:oratio /home/oratio/.local/share/applications/FNK0113.desktop

passwd – changer le mot de passe.

passwd

usermod – modifier un compte utilisateur, par exemple l'ajouter à un groupe.

sudo usermod -aG dialout $USER

whoami – affiche l'utilisateur connecté.

whoami

sudo – exécuter une commande en tant qu'administrateur.

Recherche

awk – extraire des colonnes d'un texte, par exemple awk '{print $2}'.

find – chercher des fichiers par nom ou type.
Options : -name, -iname, -type f

find ~/Freenove_Tower_Cooler_for_Raspberry_Pi -iname "*icon*"
find /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi -type f -exec chmod 644 {} \;
find ~/ -maxdepth 4 -type f \( -name "app_ui_menu.py" -o -name "main.py" \) 2>/dev/null

grep – chercher du texte dans des fichiers ou des sorties.
Options : -n numéro de ligne, -i sans tenir compte de la casse, -R récursif, -E motif

grep -E '^(autologin-user|autologin-session|user-session)' /etc/lightdm/lightdm.conf
grep -R "Name=FNK0113" ~/.local/share/applications /usr/share/applications 2>/dev/null
grep -n "screen3_is_run_on_oled" ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/task_oled.py

sed – découper des lignes ou remplacer du texte.
Options : -n 'A,Bp' afficher des lignes, -i modifier le fichier

sed -i 's/Freenove/Oratio/g' Code/create_desktop_shortcut.py
sed -n '345,385p' ~/Oratio_Control_Center/Code/app_ui_oled.py
sed -i 's/\.red/.r/g; s/\.green/.g/g; s/\.blue/.b/g' arcade.cc

which – montre où un programme est installé (ou s'il l'est).

which wmenu-run
which arduino-ide
which labwc-menu-generator

Paquets

apt – gestionnaire de paquets : installer, mettre à jour et supprimer des programmes.
Options : update, upgrade, full-upgrade, install, remove, autoremove, search

sudo apt install git python3-pip python3-pil python3-requests python3-dev make g++
sudo apt update && sudo apt full-upgrade -y && sudo apt autoremove -y && sudo apt clean
sudo apt install -y git curl python3 python3-venv python3-pip portaudio19-dev espeak alsa-utils

curl – charger des fichiers ou des scripts d'installation depuis Internet.
Options : -fsSL silencieux, suit les redirections, s'arrête en cas d'erreur

curl -fsSL https://ollama.com/install.sh | sh
curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh

git – télécharger des projets depuis GitHub (git clone) et gérer les versions.

git clone https://github.com/hzeller/rpi-rgb-led-matrix.git
git clone --depth 1 https://github.com/waveshareteam/RGB-Matrix-Px-xx.git
git clone https://github.com/Freenove/Freenove_Tower_Cooler_for_Raspberry_Pi.git

pip – installer des bibliothèques Python.
Options : pip install <paket>

pip install openwakeword
pip install openai-whisper
pip install kivy requests pillow

pip3 – comme pip, expressément pour Python 3.

pip3 --version

snap – gestionnaire de paquets supplémentaire (paquets Snap).

sudo snap install snapd
sudo snap install pycharm --classic

wget – télécharger des fichiers depuis Internet.

wget URL

Shell

bash – exécuter un script shell (bash script.sh) – marche aussi sans +x.

sudo bash ./raspiBackupInstallUI.sh

date – afficher la date et l'heure.

date '+%H:%M:%S'

sleep – attendre un certain temps, par exemple sleep 5.

sleep 12
sleep 30
sleep 60

source – charger un fichier dans le shell en cours, par exemple source ~/.bashrc.

source ~/.bashrc
source venv/bin/activate

watch – répéter une commande à intervalles fixes.
Options : -n 1 chaque seconde

watch -n 1 vcgencmd get_throttled

history – toutes les commandes précédentes ; history | grep wlr.

man – mode d'emploi détaillé d'une commande.

alias – raccourci pour une longue commande.

export – définir une variable (variable d'environnement).

Programmation

arduino-cli – Arduino sans IDE : trouver la carte, compiler, téléverser, bibliothèques.
Options : board list, core install, lib install, compile, upload

arduino-cli lib install "Adafruit GFX Library"
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old OLED_Test
arduino-cli upload -p /dev/ttyUSB0 --fqbn arduino:avr:nano:cpu=atmega328old OLED_Test

arduino-ide – l'environnement de développement graphique d'Arduino.

arduino-ide

avrdude – lit et écrit des programmes sur les puces AVR (Arduino).
Options : -U flash:r: lire, -U flash:w: écrire

avrdude -c arduino -p m328p -P COM3 -b 115200 -U flash:w:backup.hex:i

cmake – produit des instructions de construction pour de plus gros projets C++.

cmake --build build
cmake -S . -B build -G Ninja -DPANEL_PROFILE=64X32_1_16

code – ouvre VS Code.

code --version

esptool.py – lit, écrit et efface la flash des puces ESP32.
Options : read_flash, write_flash

esptool.py --chip esp32s3 --port COM3 read_flash 0 0x1000000 backup.bin

g++ – compilateur C++. Transforme le code source en programme.
Options : -O3 rapide, -o nom de sortie, -I dossier d'en-têtes, -l bibliothèque

g++ -Wall -O3 -I../include nature3.cc -o nature3 -L../lib -lrgbmatrix -lrt -lm -lpthread

geany – éditeur graphique simple pour Python.

sudo geany ~/Desktop/FNK0113.desktop
sudo geany ~/Oratio_Control_Center/Code/app_ui.py

make – construit un projet d'après un plan de construction (Makefile).

make meinprojekt
make build-python PYTHON=$(which python3)
sudo make install-python PYTHON=$(which python3)

pio – PlatformIO dans le terminal : compiler, téléverser, paquets.
Options : run, run -t upload, pkg update, system prune

pio run --target upload
pio system prune --force
pio pkg install -g -p platformio/toolchain-gccarmnoneeabi

python – lancer Python ou exécuter un programme Python.

sudo python app_ui.py
python convert_slots.py
sudo python ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_ui.py

python3 – lancer Python 3, par exemple python3 app_ui.py.

python3 /home/oratio/Oratio_Control_Center/Code/app_ui.py
sudo python3 runtext.py --led-rows=32 --led-cols=64 "Hallo Oratio"
sudo python3 clock.py --led-rows=32 --led-cols=64 --led-chain=1 --led-slowdown-gpio=4

KI

ollama – charger et lancer des modèles d'IA locaux.
Options : pull, run

ollama run gemma3:4b
ollama run qwen2.5:0.5b
ollama pull qwen2.5:0.5b

Processus

htop – surveillance du système plus confortable.

kill – terminer un processus par son numéro.

kill PID
kill $PID
kill -9 PID

killall – terminer tous les processus portant un nom.

killall pcmanfm

pkill – terminer un processus par son nom.
Options : -f ligne de commande entière

pkill -f app_ui.py

ps – afficher les processus en cours.
Options : aux tous

ps -ef | grep task_
ps aux | grep display_watchdog

top – surveillance du système en direct (quitter avec q).

Services

crontab – tâches planifiées.
Options : -e modifier, -l afficher

crontab -e
crontab -l

dmesg – messages du noyau : qu'est-ce qui a été reconnu en dernier ?

sudo dmesg | tail -n 30
dmesg | grep -iE 'pci|pcie|nvme|ahci|sata'

journalctl – lire les messages système (journaux).
Options : -n 50, -f

journalctl -n 50
sudo journalctl -u task_led.service -n 50

loginctl – gérer les sessions et les connexions.

loginctl show-session $(loginctl | grep oratio | awk '{print $1}') -p Type

systemctl – piloter et afficher les services d'arrière-plan.
Options : status, enable, restart, --user

sudo systemctl restart task_led.service
sudo systemctl restart task_fan.service
systemctl status display-manager --no-pager

Système

free – afficher la mémoire vive.
Options : -h

free -h

hostname – nom de l'appareil ; hostname -I montre l'adresse IP.

hostname
hostname -I

hostnamectl – changer le nom de l'appareil durablement.

hostnamectl

lscpu – informations sur le processeur.

lscpu

poweroff – éteindre.

sudo poweroff

reboot – redémarrer.

sudo reboot

shutdown – arrêter.
Options : now, -h

sudo shutdown now
sudo shutdown -h now

uname – infos sur le noyau et le système.
Options : -a tout

uname -m
uname -a

uptime – durée de fonctionnement et charge.

Disques

blkid – UUID et type des disques.

sudo blkid

dd – copier des données bloc par bloc, aussi pour des tests de vitesse. Une mauvaise cible détruit des données.

dd if=/dev/zero of=test.img bs=1M count=1024 conv=fdatasync

df – afficher l'espace libre.
Options : -h

df -h /mnt/ssd
df = Disk Free

fdisk – afficher et modifier les partitions.
Options : -l afficher

sudo fdisk /dev/sda

findmnt – montre tous les disques montés sous forme d'arbre.

findmnt
findmnt /

fio – test de vitesse précis pour disques.

sudo fio --name=USB-Read-Test --filename=/dev/sda --rw=read --bs=1M --size=2G --direct=1
sudo fio --name=PCIe-Read-Test --filename=/dev/sdb --rw=read --bs=1M --size=2G --direct=1

hdparm – mesurer la vitesse de lecture d'un disque.
Options : -Tt

sudo hdparm -Tt /dev/sda
sudo hdparm -Tt /dev/nvme0n1
sudo hdparm -Tt /dev/mmcblk0

lsblk – lister tous les disques et partitions. À utiliser avant tout formatage.
Options : -f avec système de fichiers

lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
lsblk -o NAME,SIZE,TYPE,FSTYPE,LABEL,MOUNTPOINTS

mkfs.ext4 – créer le système de fichiers ext4 (formater). Efface toutes les données de la partition.
Options : -L NAME désignation

sudo mkfs.ext4 /dev/nvme0n1p2
sudo mkfs.ext4 /dev/nvme0n1p1
sudo mkfs.ext4 -L BACKUP /dev/sda1

mount – monter un disque dans un dossier.

sudo mount /dev/sdb2 /mnt/ssd
sudo mount /dev/sda2 /mnt/ssd
sudo mount /dev/nvme0n1p1 /mnt/nvme

parted – créer des tables de partitions et des partitions.
Options : mklabel gpt, mkpart

sudo parted -s /dev/nvme0n1 mkpart primary ext4 0% 100%
sudo parted -s /dev/sda mklabel gpt mkpart primary ext4 0% 100%

raspiBackup – sauvegarde tout le système, aussi comme clone amorçable.

sudo raspiBackup

umount – démonter un disque.

sudo umount /backup
sudo umount /dev/sda1
sudo umount /mnt/nvme

Raspberry Pi

raspi-config – menu de configuration : I²C, SPI, ordre de démarrage, …

sudo raspi-config

rpi-eeprom-config – montre les réglages dans l'EEPROM, par exemple BOOT_ORDER.

sudo rpi-eeprom-config | grep BOOT_ORDER

rpi-eeprom-update – met à jour le firmware de l'EEPROM.

sudo rpi-eeprom-update

vcgencmd – valeurs matérielles : température, fréquence, tension, bridage.
Options : measure_temp, get_throttled, measure_clock arm

vcgencmd get_throttled
vcgencmd measure_volts
vcgencmd measure_clock arm

gpio readall

gpiod

gpioinfo

gpiozero

i2cdetect -y 1

lsusb

bluetoothctl devices

iwconfig

nmcli device wifi list

Son

aplay – lire des fichiers audio ; aplay -l liste les périphériques de sortie.

aplay test.wav

arecord – enregistrer ; arecord -l liste les microphones.
Options : -D appareil, -d durée

arecord -d 5 test.wav
arecord -D plughw:1,0 -f cd -t wav -d 5 test.wav

pactl list short sinks

wpctl – piloter l'audio sous PipeWire, par exemple le volume.

Écran

kanshi – applique automatiquement des profils d'écran quand des moniteurs sont branchés.

kanshi --version
kanshi -c ~/.config/kanshi/config

wlr-randr – réglages d'écran sous Wayland : résolution, échelle, rotation.
Options : --output, --mode, --scale, --transform

wlr-randr --output "$OUTPUT" --scale "$SCALE"
wlr-randr --output HDMI-A-1 --mode 1920x1080 --transform 180
wlr-randr --output HDMI-A-2 --mode 3840x2160 --scale 2 --transform 180

xrandr – la même chose sous X11.
Options : --output, --mode, --rate

xrandr --output HDMI-2 --mode 1920x1080
xrandr --output HDMI-1 --mode 1920x1080 --rate 60

A.3 Lancer ses propres programmes (`./nom`)

Un programme compilé soi-même se lance avec ./ devant. Exemples de tels noms de programmes : ./arcade, ./clock, ./demo, ./feuerwerk_lernen, ./led-image-viewer, ./mega, ./meinprojekt, ./nature, ./nature2, ./nature3, ./nature4, ./oratio, ./oratio_cosmos, ./oratio_cosmos_plus, ./oratio_final, ./oratio_krass, ./oratio_show, ./projektname, ./runtext, ./scrolling-text-example, ./smartdisplay, ./text-example. Pour la matrice, il faut le plus souvent sudo devant et les options --led-rows=32 --led-cols=64 --led-slowdown-gpio=4.
