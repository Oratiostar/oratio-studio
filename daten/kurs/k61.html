61.1 Python: wichtige Unterschiede

  • print schreibt Text in das Terminal. Zum Suchen von Fehlern ist es das einfachste Werkzeug (print("hier")).
  • os.system("befehl") startet einen Befehl, ist aber unsicher bei Eingaben von außen. Besser ist subprocess.run([...]) oder subprocess.Popen([...]) mit einer Liste aus Befehl und Argumenten.
  • JSON als Datenbank: Für kleine Programme ist eine JSON-Datei die einfachste Speicherung (Namen, Pfade, Einstellungen). Grundregel: Einstellungen in JSON, Logik im Code. Dann lassen sich Apps hinzufügen, ohne den Code zu ändern.
  • Kann jeder Linux-Befehl benutzt werden? Ja, jeder Befehl, den das Terminal kennt, lässt sich mit subprocess starten.
  • Groß- und Kleinschreibung: Python unterscheidet Name und name. Klassen schreibt man üblicherweise GroßBuchstabe, Funktionen und Variablen klein_mit_unterstrich.
  • ComboBox oder QInputDialog: Eine ComboBox ist ein Auswahlfeld, das im Fenster bleibt. QInputDialog ist ein Popup-Fenster mit einer Eingabe oder Auswahl.
  • PyQt5 oder PyQt6: Die beiden sind sich ähnlich, aber nicht kompatibel (zum Beispiel exec_() gegenüber exec()). Eine Version konsequent verwenden.

61.2 Drag and Drop in Qt

Statt Mausereignisse selbst zu verwalten (mousePressEvent, mouseReleaseEvent), bietet Qt eine eingebaute Drag-and-Drop-Unterstützung. Sie ist stabiler, wenn viele Elemente verschoben werden. Beim Ziehen kann man das Element abdunkeln, indem man seine Farbe aus der Grundfarbe berechnet.

61.3 Python oder C++ für mein Projekt?

C++ (zum Beispiel mit Qt) ist schneller und braucht weniger Speicher, aber die Entwicklung dauert länger. Für eine Oberfläche mit Knöpfen, die Skripte starten, ist Python schnell genug. Ein Programm für den Raspberry Pi lässt sich in C++ neu schreiben und dort kompilieren, es läuft dann nur auf der passenden Architektur (ARM64).

61.4 Eigenes Programm früher starten oder als Startbild

Autostart (Kapitel 5) startet nach der Anmeldung. Soll früher gestartet werden (zum Beispiel ein Video beim Hochfahren), braucht es einen systemd-Dienst. Dienste starten vor der Anmeldung und können ein Programm oder Video sofort abspielen. Die Abspielzeit lässt sich mit Start- und Endzeit steuern, zum Beispiel mit mpv --start=8 --end=19 video.mp4.

61.5 Steam Deck und Retro-Spiele

PS1-Dateiformate:

Format Beschreibung
BIN + CUE Abbild plus Beschreibung der Spuren
CHD komprimiertes Abbild, spart Platz, wird von den meisten Emulatoren gelesen (empfohlen)
PBP Sony-Paketformat, oft für eigenständige Spiele
M3U Wiedergabeliste für Spiele mit mehreren Discs

Umwandeln: chdman createcd -i spiel.cue -o spiel.chd. Bei mehreren Discs legt man pro Disc eine CHD an und eine .m3u mit den Dateinamen.

BIOS: Unter RetroDECK im Ordner ~/retrodeck/bios/. PS2 braucht einen Unterordner ps2, weil der Emulator (PCSX2) die Dateien dort erwartet.

Bazzite oder SteamOS? SteamOS ist das Valve-System für das Deck. Bazzite ist ein ähnliches System auf Fedora-Basis, das auch auf anderen Handhelds läuft (zum Beispiel Intel- und AMD-Geräten).

Speicher erweitern: Steam Deck und ROG Ally nehmen eine microSD-Karte oder eine austauschbare M.2-SSD auf (Größe 2230 oder 2242). Prüfe die Bauform vor dem Kauf.
