24.1 Qu’est-ce qui est possible ?

Un grand modèle d'IA comme un chatbot en ligne ne tourne pas sur un Pi. Un petit assistant local, si. La chaîne :

Mikrofon hört  →  Sprache wird zu Text  →  KI verarbeitet  →  Antwort wird gesprochen

24.2 Les composants

Tâche Programme
IA de langage locale Ollama avec un petit modèle (par exemple qwen2.5:0.5b)
Parole vers texte Whisper ou Vosk
Texte vers parole Piper (rapide et entièrement local)
Mot de réveil (le nom d'appel) Porcupine (ici le plan initial ; dans le Control Center, la détection est plus tard assurée par Vosk avec le nom réglé, chapitre 39.3)

24.3 Matériel

Obligatoire : Raspberry Pi 4 (4 ou 8 Go) ou Pi 5, microSD 32 Go ou plus, alimentation 5 V / 3 A, ventilateur, microphone USB (ou ReSpeaker 2-Mic HAT), haut-parleur, Wi-Fi. Facultatif : écran, matrice LED, ESP32, relais, capteurs.

24.4 Pas à pas

1. Préparer le Pi

sudo apt update
sudo apt upgrade -y
sudo apt install -y git curl python3 python3-venv python3-pip portaudio19-dev espeak alsa-utils

2. Tester le microphone et le haut-parleur

arecord -l
speaker-test -t wav

3. Installer Ollama et charger un petit modèle

curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:0.5b
ollama run qwen2.5:0.5b

Puis taper « Hallo, wer bist du ? ». S'il répond, l'IA locale fonctionne.

4. Premier programme avec son propre nom (texte seulement, encore sans voix)

nano oratio_ai.py
import subprocess

name = "Oratio AI"

while True:
    frage = input("Du: ")

    if frage.lower() in ["exit", "quit", "ende"]:
        break

    prompt = f"Du bist {name}. Antworte kurz, freundlich und auf Deutsch. Frage: {frage}"

    antwort = subprocess.check_output(
        ["ollama", "run", "qwen2.5:0.5b", prompt],
        text=True
    )

    print(f"{name}: {antwort}")
python3 oratio_ai.py

5. Ensuite : microphone et réponse parlée (Whisper/Vosk + Piper), puis le mot de réveil.

24.5 Noms et langue

J'ai rassemblé des idées pour le nom de l'assistant, par exemple ORAI (ORAtio + AI), Oris, OraMind, OraNova. Une langue à soi (par exemple la langue maternelle) peut être prise en charge en collectant des phrases d'exemple et des mots-clés et en les associant à des actions (« Licht an », « Fernseher aus »). L'assistant n'a pas besoin de connaître officiellement la langue si la liste de commandes est tenue à jour soi-même.

24.6 Combien de commandes le Pi peut-il piloter ?

Ma question était : « J'ai des milliers de commandes, mais mon GPIO n'a pas autant de connecteurs. » En bref : les commandes sont dans le logiciel (liste ou base de données). Les broches ne sont nécessaires que pour ce qui est réellement commuté. On obtient plus de sorties avec des extensions (par exemple des expanseurs de ports I²C) ou en y raccordant un ESP32 comme assistant.
