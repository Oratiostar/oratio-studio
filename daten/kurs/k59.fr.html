Courtes réponses à des questions qui reviennent sans cesse pendant l'apprentissage. Chaque élément se suffit à lui-même.

59.1 Quel Raspberry Pi, quel système ?

Pi 3 Pi 4 Pi 5
Processeur plus faible nettement plus rapide nettement plus rapide que le Pi 4
Mémoire 1 GB 2 à 8 Go 4, 8 ou 16 Go
Interface pour SSD seulement USB 2 USB 3 USB 3 et PCIe (NVMe via adaptateur)
Bloc d'alimentation 5 V / 2,5 A 5 V / 3 A 5 V / 5 A
Refroidissement le plus souvent inutile recommandé ventilateur recommandé
  • 32 bits contre 64 bits : sur Pi 4 et 5, on prend le 64 bits. Beaucoup de programmes (par exemple les versions actuelles de VS Code ou d'Arduino) n'existent plus que pour lui. Le 32 bits n'a de sens que pour de très vieux appareils.
  • Lite, Desktop ou Full : Lite n'a pas d'interface (serveur, terminal), Desktop a l'interface graphique, Full apporte en plus beaucoup de logiciels. Pour apprendre, Desktop suffit.
  • Bookworm et Trixie : noms des versions de Debian (12 et 13). Trixie est plus récente. Les deux utilisent par défaut Wayland avec le gestionnaire de fenêtres labwc.
  • Mettre la carte SD dans un autre modèle : cela marche le plus souvent, tant que le système est construit pour les deux modèles. Un système construit pour le Pi 5 ne tourne pas sur un Pi 3 et inversement.

59.2 Écrire une image sur une carte SD

  1. Installer Raspberry Pi Imager (sudo apt install rpi-imager ou depuis le site web) et le lancer.
  2. Choisir le système d'exploitation, choisir le support de stockage, saisir les réglages (nom d'utilisateur, WLAN, SSH).
  3. Écrire et attendre.

Pour un fichier fini avec l'extension .xz, la décompression est inutile : l'Imager le lit directement (Choisir une image personnalisée). Pour décompresser dans le terminal : unxz datei.img.xz.

Autres programmes : balenaEtcher (Windows, Mac, Linux), Win32 Disk Imager (Windows, pour écrire et sauvegarder une image), dd dans le terminal (rapide, mais un mauvais nom de cible écrase le mauvais disque). Tirer une image depuis un disque se fait avec Win32 Disk Imager ou dd.

59.3 Numérotation des GPIO

Une broche a deux numéros :

Numéro Signification
Numéro de broche physique (1 à 40) Position sur le connecteur à broches
Numéro BCM (GPIO 17, GPIO 18 ...) Nom de la connexion du processeur

Les schémas sur Internet diffèrent, parce que certains étiquettent le numéro physique et d'autres le numéro BCM. En Python, on utilise en règle générale le numéro BCM. Toujours vérifier d'abord quelle numérotation est visée.

59.4 SSH : à quoi ça sert ?

SSH ouvre un terminal sur le Pi depuis un autre appareil (PC, téléphone). On peut ainsi saisir des commandes, copier des fichiers (scp, sftp) et faire fonctionner le Pi sans écran (headless). Activer : sudo raspi-config → Interface Options → SSH. Se connecter : ssh oratio@<IP-Adresse> ; l'IP s'affiche avec hostname -I.

59.5 SSD, NVMe et adaptateurs

  • SSD NVMe sur le Pi 5 : via un HAT M.2 sur l'interface PCIe. Le Pi 5 travaille par défaut en PCIe Gen 2 (environ 500 Mo/s) et peut être passé en Gen 3 avec dtparam=pciex1_gen=3 (pas officiellement garanti).
  • Une seule ligne PCIe : plus d'appareils sur une ligne ne passent que par un switch PCIe, et ils se partagent la vitesse.
  • Clés du connecteur M.2 : les SSD à clé M (une encoche) sont NVMe. Un SSD à deux encoches (B+M) est souvent un SSD SATA, qu'un adaptateur NVMe ne pilote pas. Faire attention à la plaque signalétique.
  • Boîtier USB : si un SSD sur adaptateur USB affiche 0 B, voir le chapitre 56.3.
  • Démarrer depuis un SSD : sudo raspi-config → Advanced Options → Boot Order (chapitre 26.7).
  • Où regarder les valeurs ? lsblk (disques), sudo fdisk -l (l'option -l signifie list), sudo nvme list.

59.6 Plus d’accessoires pour le Pi 5

  • Les HAT sont des cartes enfichables, par exemple pour SSD, IA ou écran. Les HAT montés dessous (HAT+ et similaires) utilisent le connecteur PCIe.
  • Le NPU (Neural Processing Unit) est un accélérateur pour les tâches d'IA (images, voix). Ce n'est pas un remplaçant du processeur, mais une carte supplémentaire, comme l'AI HAT.
  • Le Compute Module est le Pi sans connecteurs, à intégrer dans ses propres appareils. Le Pi normal a toutes les prises sur la carte.
  • Home Assistant OS est un système pour la maison connectée, qui se commande par le navigateur.
  • Connecter des manettes : par Bluetooth (bluetoothctl) ou par USB. Sous Batocera/RetroPie, il y a une affectation de manettes propre.

59.7 Température et charge

  • Le Pi 5 se situe en fonctionnement normal autour de 40 à 60 °C. À partir d'environ 80 °C, il réduit la puissance.
  • Température : vcgencmd measure_temp. État de la tension et du bridage : vcgencmd get_throttled.
  • CPU saturé ? top ou htop montre quel programme demande la puissance. Terminer avec kill PID.

59.9 Terminal : Bash, sh et scripts

  • Le shell est le programme qui lit les entrées. Bash (« Bourne Again SHell », un jeu de mots sur son prédécesseur Bourne Shell) est le shell habituel sous Linux.
  • Un fichier xyz.sh est un script shell : un fichier texte avec des commandes. Il tourne dans Bash si la première ligne est #!/bin/bash.
  • Le rendre exécutable : chmod +x xyz.sh, lancer avec ./xyz.sh.
  • alias name='befehl' dans ~/.bashrc crée un raccourci, source ~/.bashrc le recharge.
  • cd et sudo : cd change de dossier, sudo exécute une commande avec les droits d'administrateur. Ce sont deux choses totalement différentes.

59.10 Affichages

  • KMS (dtoverlay=vc4-kms-v3d dans /boot/firmware/config.txt) est le pilote graphique moderne. Le fichier se modifie avec sudo nano /boot/firmware/config.txt, les modifications valent après le redémarrage.
  • Full HD contre 4K : la 4K a quatre fois plus de pixels. Avec une échelle de 2, la 4K paraît comme du Full HD, mais plus nette. Le Pi 4 gère la 4K à 60 Hz avec un écran (avec deux écrans 4K, 30 Hz chacun), le Pi 5 gère la 4K à 60 Hz aussi avec deux écrans.
  • Faire pivoter l'écran : wlr-randr --output HDMI-A-1 --transform 180.
  • Affichage sur le téléphone : via VNC (Raspberry Pi Connect ou RealVNC) ou par streaming d'écran. C'est la voie officielle sans matériel supplémentaire : Raspberry Pi Connect.
  • Signal HDMI : une image se compose de pixels, chaque pixel de trois valeurs de couleur (rouge, vert, bleu, 8 bits chacune). Ces valeurs sont transmises comme suite de uns et de zéros sur plusieurs paires de lignes. La 4K à 60 Hz demande un câble adapté (HDMI 2.0).
  • Écran avec connexion propre (DSI, GPIO) : vérifier si l'écran a une entrée HDMI ou SPI/DSI. Pour le tactile, il faut en plus une liaison USB ou I²C et le plus souvent une alimentation 5 V.
