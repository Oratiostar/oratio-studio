5.1 Voir et terminer les processus

ps aux                        # alle laufenden Prozesse
ps aux | grep kanshi          # ist Kanshi gestartet?
top                           # live, beenden mit q
htop                          # komfortabler (sudo apt install htop)
kill 1234                     # Prozess mit der Nummer 1234 beenden
pkill kanshi                  # Prozess nach Namen beenden
pkill -f app_ui.py            # Prozess nach ganzer Befehlszeile beenden

Voici comment j’ai trouvé l’erreur avec Kanshi : ps aux | grep kanshi n’affichait que la ligne de grep elle-même. Cela veut dire : Kanshi ne tourne pas du tout, bien qu’il figure dans le démarrage automatique. La cause était une erreur de syntaxe dans le fichier de configuration (voir chapitre 10.6).

5.2 systemd – les services

Sur le Pi, les services d’arrière-plan tournent sous systemd.

systemctl status ssh --no-pager       # Zustand ansehen
sudo systemctl enable --now ssh       # jetzt starten und beim Boot starten
sudo systemctl restart <dienst>       # neu starten
systemctl --user status kanshi        # Dienst des eigenen Benutzers
systemctl get-default                 # grafisch (graphical.target) oder nicht

5.3 Lire les journaux

journalctl -n 50       # letzte 50 Systemmeldungen
journalctl -f          # live mitlesen
dmesg | tail           # letzte Kernel-Meldungen (z. B. neue USB-Geräte)

dmesg montre ce que le noyau a détecté quand on branche quelque chose, par exemple un Arduino qui apparaît comme ttyUSB0.

5.4 Démarrage automatique à la connexion (bureau)

Les fichiers du dossier ~/.config/autostart sont lancés à la connexion. Chaque fichier est une Desktop Entry :

[Desktop Entry]
Type=Application
Name=Display Watchdog
Exec=/home/oratio/display_watchdog.sh

Signification des lignes :

  • [Desktop Entry] – début de la configuration
  • Type=Application – c’est un programme
  • Name= – nom affiché
  • Exec= – quel programme est lancé

Chaque fichier de autostart décrit un programme. Les fichiers n’ont pas tous la même longueur. La partie obligatoire se compose le plus souvent de ces quatre lignes.

Attention : le script s’appelle .sh, le fichier de démarrage automatique s’appelle .desktop. J’ai déjà confondu ces deux extensions.

Avec labwc (le gestionnaire de fenêtres de Raspberry Pi OS Trixie), il existe en plus le fichier ~/.config/labwc/autostart. On y trouve par exemple la ligne kanshi &.

5.5 cron – tâches planifiées

crontab -e     # Zeitplan bearbeiten
crontab -l     # Zeitplan anzeigen

Une ligne comporte cinq champs de temps (minute, heure, jour, mois, jour de la semaine), puis la commande. Exemple « chaque dimanche à 3 h » : 0 3 * * 0 /home/oratio/backup.sh. Une sauvegarde tourne ainsi sans intervention de ma part.

5.6 Redémarrer et éteindre

sudo reboot
sudo shutdown now
sudo shutdown -h now
