Cette liste contient ce dont on a le plus souvent besoin sur le Pi.

6.1 Système

uname -a                    # Kernel und Systeminfos
hostname                    # Name des Geräts
cat /etc/os-release         # welche Version von Raspberry Pi OS
cat /proc/device-tree/model # welches Pi-Modell
uptime                      # Laufzeit und Last
lscpu                       # Prozessor
free -h                     # Arbeitsspeicher (RAM)
df -h                       # freier Speicherplatz

6.2 Température, fréquence, alimentation

vcgencmd measure_temp       # CPU-Temperatur
vcgencmd get_throttled      # Probleme mit Strom/Wärme? (0x0 = alles gut)
vcgencmd measure_clock arm  # aktuelle Taktfrequenz
vcgencmd measure_volts      # Spannung
watch -n 1 vcgencmd measure_temp    # Temperatur live, jede Sekunde

get_throttled est très utile : si l’alimentation est trop faible ou si le Pi chauffe trop, cela apparaît ici. Une valeur différente de 0x0 signifie qu’il y a eu un problème à un moment donné (sous-tension ou bridage).

6.3 Disques et USB

lsblk                       # alle Laufwerke
sudo fdisk -l               # Laufwerke im Detail
lsusb                       # USB-Geräte
dmesg | tail                # was wurde zuletzt erkannt?
lspci                       # PCIe-Geräte (nur Pi 5: NVMe, AI-HAT)

6.4 Réseau

hostname -I                 # nur die IP-Adresse(n)
ip a                        # alle Netzwerkdetails
ping google.com             # Internet testen (Strg+C beendet)
iwconfig                    # WLAN-Infos
nmcli device wifi list      # verfügbare WLANs
ss -tulnp                   # offene Verbindungen und Ports
ssh oratio@<IP-ADRESSE>     # von einem anderen Gerät auf den Pi verbinden

6.5 La configuration

sudo raspi-config           # das Hauptmenü für Einstellungen
sudo nano /boot/firmware/config.txt     # Firmware-Konfiguration
sudo nano /boot/firmware/cmdline.txt    # Kernel-Parameter (nur EINE Zeile!)
