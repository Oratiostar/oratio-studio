52.4 Double démarrage

Symptôme Commande Interprétation Solution
Un seul système démarre efibootmgr -v Entrée manquante efibootmgr / bcdboot (Windows) / recréer GRUB
La mise à jour de Windows détruit le menu de démarrage – écrase l'ordre de démarrage Ordre dans l'UEFI ou avec efibootmgr -o
Heure fausse sous Linux/Windows timedatectl Windows prend l'heure locale, Linux l'UTC Windows : registre RealTimeIsUniversal ; ou Linux : timedatectl set-local-rtc 1
Windows ne voit pas la partition Linux – ext4 inconnu volontaire ; échanger des fichiers via une partition NTFS/exFAT
Partition trop petite lsblk – avant de la réduire, sauvegarde, puis avec gparted

52.5 Règle fondamentale commune

  1. Sauvegarder avant tout travail sur disque/partition – les erreurs y sont irréversibles.
  2. D'abord lire, puis écrire : lsblk, fdisk -l, blkid montrent l'état sans rien modifier.
  3. Vérifier deux fois la cible : avec dd, un mauvais nom de cible, c'est la fin des données.
