57.3 Windows und PowerShell

Cannot bind argument to parameter 'Text' because it is an empty string.

Ein Cmdlet wie Write-Host oder Write-Progress bekam einen leeren Text für einen Pflichtparameter. Die Variable ist leer oder $null. Prüfen (if ($text) { ... }) oder einen Standardwert setzen ($text = "-").
