Dieses Verzeichnis enthält die Befehle des Kurses, geordnet nach Thema (A.1), als Index von A bis Z (A.2) und die Aufrufe eigener Programme (A.3). Die Beispiele sind echte Zeilen aus Projekten, teilweise gekürzt.

A.1 Nach Themen

Dateien

cat – Dateiinhalt im Terminal ausgeben. Gut, um kleine Konfigurationsdateien zu prüfen.

cat /home/oratio/Oratio_Control_Center/ANLEITUNG.txt
cat ~/Desktop/FNK0113.desktop ~/Desktop/pi-apps.desktop
cat ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json

cd – Ordner wechseln. cd .. geht eine Ebene zurück, cd ~ ins Home-Verzeichnis.

cd ~/Desktop/RGB-Matrix-Px-xx/example/Rasberry-Pi/bindings/python/samples
cd ~/Desktop/RGB-Matrix-Px-xx/example/Raspberry-Pi/bindings/python/samples
cd /home/oratio/Desktop/RGB-Matrix-Px-xx/example/Rasberry-Pi/examples-api-use

cp – Dateien kopieren. Mit -r auch Ordner.
Optionen: -r rekursiv

sudo cp /boot/firmware/cmdline.txt.backup /boot/firmware/cmdline.txt
cp -r ~/Freenove_Tower_Cooler_for_Raspberry_Pi/* ~/Oratio_Control_Center/
cp /pfad/zur/datei /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/

du – Platzverbrauch von Ordnern anzeigen.
Optionen: -h lesbare Größen, -s nur Summe

du -ah / | sort -hr | head -20
du -sh ~/Freenove_Tower_Cooler_for_Raspberry_Pi
sudo du -xh / --max-depth=1 2>/dev/null | sort -h

echo – Text ausgeben. Mit >> an eine Datei anhängen.

echo "Scale wird gesetzt auf: $SCALE"
echo 'export PICO_SDK_PATH=$HOME/pico-sdk' >> ~/.bashrc
echo "alias fhd='wlr-randr --output HDMI-A-1 --mode 1920x1080'" >> ~/.bashrc

head – Erste Zeilen einer Datei oder Ausgabe zeigen.
Optionen: -n 20

head -100 app_ui.py
head -150 app_ui.py
head -20 app_ui_pi_tools.py

ln – Verknüpfung (Link) zwischen Dateien anlegen.
Optionen: -s symbolischer Link

ln -s /home/oratio/Oratio_Control_Center \

ls – Dateien und Ordner auflisten.
Optionen: -l Details und Rechte, -a auch versteckte, -d nur Ordner selbst

ls -l ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json
ls -l /home/oratio/Oratio_Control_Center/Code/picture/xpm/FNK0113.xpm
ls -l /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json

mkdir – Ordner anlegen.
Optionen: -p legt auch fehlende Zwischenordner an

mkdir -p ~/Dokumente/PlatformIO/Projects/PicoTest
mkdir -p ~/Dokumente/PlatformIO/Projects/TestPico
sudo mkdir -p /mnt/nvme && sudo mount /dev/nvme0n1p1 /mnt/nvme

mv – Dateien verschieben oder umbenennen.

mv Freenove_Tower_Cooler_for_Raspberry_Pi Oratio_Control_Center
mv Freenove_Tower_Cooler_for_Raspberry_Pi "Horacio_Control_Center"
mv Freenove_Tower_Cooler_for_Raspberry_Pi "Oratio_Kontrollzentrum"

nano – Texteditor im Terminal. Speichern Strg+O, Enter; beenden Strg+X.

nano ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_ui_oled.py
sudo nano ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/app_config.json
nano /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/task_oled.py

rm – Dateien löschen. Endgültig, kein Papierkorb!
Optionen: -r Ordner, -f ohne Nachfrage (gefährlich)

rm /mnt/ssd/fio-testfile /mnt/ssd/test.txt
rm -rf ~/Freenove_Tower_Cooler_for_Raspberry_Pi
rm -rf ~/.platformio/packages/toolchain-gccarmnoneeabi*

tail – Letzte Zeilen zeigen.
Optionen: -f live mitlesen

tail -f app.log
tail -20 api_service.py
tail -100 /home/oratio/Oratio_Control_Center/app_ui_menu.py

tar – Archive (.tar, .tar.gz) packen und entpacken.
Optionen: -xzf entpacken, -czf packen

tar -xzvf backup.tar.gz
tar -xf pycharm-*.tar.gz
tar -czvf backup.tar.gz Dokumente

touch – Leere Datei anlegen oder Zeitstempel erneuern.

touch test.txt
touch app_ui_scripts.py
touch /mnt/ssd/test.txt && ls -l /mnt/ssd/test.txt

unzip – ZIP-Archive entpacken.

unzip backup.zip

pwd – Zeigt den aktuellen Ordner.

Rechte

chmod – Dateirechte ändern. chmod +x datei macht eine Datei ausführbar.
Optionen: +x ausführbar

chmod +x ~/.local/share/applications/FNK0113.desktop
chmod -R 755 /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi
chmod -R u+rw /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi

chown – Besitzer einer Datei oder eines Ordners ändern.
Optionen: -R auch Unterordner

sudo chown oratio:oratio app_config.json
sudo chown -R oratio:oratio /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi
sudo chown oratio:oratio /home/oratio/.local/share/applications/FNK0113.desktop

passwd – Passwort ändern.

passwd

usermod – Benutzerkonto ändern, zum Beispiel einer Gruppe hinzufügen.

sudo usermod -aG dialout $USER

whoami – Zeigt den angemeldeten Benutzer.

whoami

sudo – Befehl als Administrator ausführen.

Suchen

awk – Spalten aus Text herausziehen, zum Beispiel awk '{print $2}'.

find – Dateien nach Name oder Typ suchen.
Optionen: -name, -iname, -type f

find ~/Freenove_Tower_Cooler_for_Raspberry_Pi -iname "*icon*"
find /home/oratio/Freenove_Tower_Cooler_for_Raspberry_Pi -type f -exec chmod 644 {} \;
find ~/ -maxdepth 4 -type f \( -name "app_ui_menu.py" -o -name "main.py" \) 2>/dev/null

grep – Text in Dateien oder Ausgaben suchen.
Optionen: -n Zeilennummer, -i Groß/klein egal, -R rekursiv, -E Muster

grep -E '^(autologin-user|autologin-session|user-session)' /etc/lightdm/lightdm.conf
grep -R "Name=FNK0113" ~/.local/share/applications /usr/share/applications 2>/dev/null
grep -n "screen3_is_run_on_oled" ~/Freenove_Tower_Cooler_for_Raspberry_Pi/Code/task_oled.py

sed – Zeilen ausschneiden oder Text ersetzen.
Optionen: -n 'A,Bp' Zeilen anzeigen, -i Datei ändern

sed -i 's/Freenove/Oratio/g' Code/create_desktop_shortcut.py
sed -n '345,385p' ~/Oratio_Control_Center/Code/app_ui_oled.py
sed -i 's/\.red/.r/g; s/\.green/.g/g; s/\.blue/.b/g' arcade.cc

which – Zeigt, wo ein Programm installiert ist (oder ob überhaupt).

which wmenu-run
which arduino-ide
which labwc-menu-generator

Pakete

apt – Paketmanager: Programme installieren, aktualisieren und entfernen.
Optionen: update, upgrade, full-upgrade, install, remove, autoremove, search

sudo apt install git python3-pip python3-pil python3-requests python3-dev make g++
sudo apt update && sudo apt full-upgrade -y && sudo apt autoremove -y && sudo apt clean
sudo apt install -y git curl python3 python3-venv python3-pip portaudio19-dev espeak alsa-utils

curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh

git clone https://github.com/hzeller/rpi-rgb-led-matrix.git
git clone --depth 1 https://github.com/waveshareteam/RGB-Matrix-Px-xx.git
git clone https://github.com/Freenove/Freenove_Tower_Cooler_for_Raspberry_Pi.git

Optionen: pip install <paket>

pip install openwakeword
pip install openai-whisper
pip install kivy requests pillow

pip3 – Wie pip, ausdrücklich für Python 3.

pip3 --version

snap – Zusätzlicher Paketmanager (Snap-Pakete).

sudo snap install snapd
sudo snap install pycharm --classic

wget – Dateien aus dem Internet herunterladen.

wget URL

arduino-cli lib install "Adafruit GFX Library"
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old OLED_Test

arduino-ide

avrdude -c arduino -p m328p -P COM3 -b 115200 -U flash:w:backup.hex:i

cmake --build build

esptool.py --chip esp32s3 --port COM3 read_flash 0 0x1000000 backup.bin

g++ – C++-Compiler. Macht aus Quellcode ein Programm.
Optionen: -O3 schnell, -o Ausgabename, -I Header-Ordner, -l Bibliothek

g++ -Wall -O3 -I../include nature3.cc -o nature3 -L../lib -lrgbmatrix -lrt -lm -lpthread

make meinprojekt

sudo make install-python PYTHON=$(which python3)

pio run --target upload

lscpu

Laufwerke

blkid – UUID und Typ der Laufwerke.

sudo blkid

dd – Daten Block für Block kopieren, auch für Speedtests. Falsches Ziel zerstört Daten.

dd if=/dev/zero of=test.img bs=1M count=1024 conv=fdatasync

df – Freien Speicherplatz anzeigen.
Optionen: -h

df -h /mnt/ssd
df = Disk Free

fdisk – Partitionen anzeigen und bearbeiten.
Optionen: -l anzeigen

sudo fdisk /dev/sda

findmnt – Zeigt alle eingehängten Laufwerke als Baum.

findmnt
findmnt /

fio – Genauer Geschwindigkeitstest für Laufwerke.

sudo fio --name=USB-Read-Test --filename=/dev/sda --rw=read --bs=1M --size=2G --direct=1
sudo fio --name=PCIe-Read-Test --filename=/dev/sdb --rw=read --bs=1M --size=2G --direct=1

hdparm – Lesegeschwindigkeit eines Laufwerks messen.
Optionen: -Tt

sudo hdparm -Tt /dev/sda
sudo hdparm -Tt /dev/nvme0n1
sudo hdparm -Tt /dev/mmcblk0

lsblk – Alle Laufwerke und Partitionen auflisten. Vor jeder Formatierung benutzen.
Optionen: -f mit Dateisystem

lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
lsblk -o NAME,SIZE,TYPE,FSTYPE,LABEL,MOUNTPOINTS

mkfs.ext4 – Dateisystem ext4 anlegen (formatieren). Löscht alle Daten der Partition.
Optionen: -L NAME Bezeichnung

sudo mkfs.ext4 /dev/nvme0n1p2
sudo mkfs.ext4 /dev/nvme0n1p1
sudo mkfs.ext4 -L BACKUP /dev/sda1

mount – Laufwerk an einem Ordner einhängen.

sudo mount /dev/sdb2 /mnt/ssd
sudo mount /dev/sda2 /mnt/ssd
sudo mount /dev/nvme0n1p1 /mnt/nvme

parted – Partitionstabellen und Partitionen anlegen.
Optionen: mklabel gpt, mkpart

sudo parted -s /dev/nvme0n1 mkpart primary ext4 0% 100%
sudo parted -s /dev/sda mklabel gpt mkpart primary ext4 0% 100%

raspiBackup – Sichert das ganze System, auch als bootfähigen Klon.

sudo raspiBackup

umount – Laufwerk aushängen.

sudo umount /backup
sudo umount /dev/sda1
sudo umount /mnt/nvme

vcgencmd measure_clock arm

gpioinfo

gpiozero

A.3 Eigene Programme starten (`./name`)

Ein selbst kompiliertes Programm wird mit ./ davor gestartet. Beispiele für solche Programmnamen: ./arcade, ./clock, ./demo, ./feuerwerk_lernen, ./led-image-viewer, ./mega, ./meinprojekt, ./nature, ./nature2, ./nature3, ./nature4, ./oratio, ./oratio_cosmos, ./oratio_cosmos_plus, ./oratio_final, ./oratio_krass, ./oratio_show, ./projektname, ./runtext, ./scrolling-text-example, ./smartdisplay, ./text-example. Für die Matrix braucht man meist sudo davor und die Optionen --led-rows=32 --led-cols=64 --led-slowdown-gpio=4.
