49.2 Strom und Stabilität

vcgencmd get_throttled

Die Zahl ist eine Bitmaske (hexadezimal):

Bit (Wert) Bedeutung
0 (0x1) jetzt Unterspannung
1 (0x2) jetzt Taktfrequenz begrenzt
2 (0x4) jetzt gedrosselt
3 (0x8) jetzt Temperaturgrenze (weich)
16 (0x10000) Unterspannung trat seit dem Start auf
17 (0x20000) Frequenzbegrenzung trat auf
18 (0x40000) Drosselung trat auf
19 (0x80000) Temperaturgrenze trat auf

0x0 ist in Ordnung. 0x50005 heißt Unterspannung und Drosselung jetzt und früher. Maßnahmen: offizielles Netzteil, kurzes gutes Kabel, nichts Stromhungriges am USB ohne eigene Versorgung. Temperatur: vcgencmd measure_temp; über 80 °C Kühlung prüfen (Lüfter dreht? Kühlkörper sitzt?).

49.4 Ton

Der Weg des Tons: Programm → Audio-Server (PipeWire) → Ausgabegerät (HDMI, Klinke, USB, Bluetooth).

wpctl status                       # PipeWire: Geräte, Standardgerät (mit *)
pactl list short sinks             # Ausgabegeräte
aplay -l                           # Tonkarten auf Kernel-Ebene
speaker-test -t wav -c 2           # Testton
wpctl set-mute @DEFAULT_AUDIO_SINK@ 0     # Stumm aufheben
wpctl set-volume @DEFAULT_AUDIO_SINK@ 0.7 # Lautstärke 70 %
Symptom Deutung Lösung
Gerät fehlt in aplay -l Kernel kennt es nicht Kabel/Anschluss; dmesg | tail
Gerät da, aber kein Ton falsches Standardgerät oder stumm Standard mit wpctl set-default ID setzen, Stumm aufheben
Ton nur über HDMI des Monitors Standard steht auf HDMI auf Klinke/USB/Bluetooth umstellen
Ton leise oder verzerrt Quelle/Verstärker Mixer alsamixer prüfen
Mikrofon leer Eingabegerät falsch pactl list short sources, Standardquelle wählen (Kapitel 30.3)
