Il existe quatre types d'appareils. L'essentiel est de comprendre ce que chacun sait faire et ne sait pas faire. Les débutants y perdent souvent du temps, par exemple quand du code Raspberry Pi ne fonctionne pas sur l'ESP32.

15.1 La grande différence

Un Raspberry Pi est un ordinateur complet sous Linux. Un microcontrôleur (Arduino, ESP32, Pico) est une petite puce sur laquelle tourne exactement un programme, sans système d'exploitation.

Raspberry Pi 4 / 5 ESP32 / ESP32-S3 Arduino Nano Raspberry Pi Pico H
Type mini-ordinateur sous Linux microcontrôleur microcontrôleur microcontrôleur (puce RP2040)
Wi-Fi / Bluetooth ja ja non non
Temps de démarrage 15–30 secondes (boot) 1–2 secondes immédiat immédiat
Consommation élevée faible très faible très faible
Programmé avec Python, C++, shell Arduino/C++ Arduino/C++ C++ (SDK Pico), MicroPython
Internet, météo, pages web directement possible via Wi-Fi avec du code dédié seulement avec du matériel supplémentaire seulement avec du matériel supplémentaire

Le « H » du Pico H signifie seulement que les barrettes de broches sont déjà soudées. Il n'a pas de Wi-Fi.

15.2 Ce qui ne tourne *pas* sur l’ESP32

Mon code pour la matrice LED sur le Raspberry Pi utilisait des éléments qui n'existent pas sur l'ESP32 :

#include "../include/led-matrix.h"   // eine Raspberry-Pi-Bibliothek
system("hostname -I");               // Linux-Befehle
popen(...)

Sur le microcontrôleur, il n'y a pas de Linux, il faut donc réécrire certaines parties : récupérer l'heure par Wi-Fi (NTP), charger la météo directement via l'API web, utiliser une bibliothèque HUB75 compatible ESP32. Les animations (Mario, radar, feu d'artifice) peuvent être reprises, mais le code est à réécrire.

Règle empirique : si un programme a besoin d'Internet, de fichiers et de commandes Linux, le Pi convient. S'il doit démarrer vite, consommer peu et simplement afficher quelque chose, un microcontrôleur convient.

15.3 Sa propre IA ?

  • Sur l'ESP32, très peu de choses sont possibles : mot de réveil comme « Hallo Oratio », commandes vocales simples, capteurs. Un grand chatbot n'y tourne pas.
  • Sur le Pi 4 ou le Pi 5, un petit assistant vocal local est possible (chapitre 24).
  • L'ESP32 peut servir d'assistant : commander capteurs, relais, boutons et lumière pendant que l'IA tourne sur le Pi.
