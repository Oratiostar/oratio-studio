57.3 Windows et PowerShell

Cannot bind argument to parameter 'Text' because it is an empty string.

Un cmdlet comme Write-Host ou Write-Progress a reçu un texte vide pour un paramètre obligatoire. La variable est vide ou $null. Vérifier (if ($text) { ... }) ou définir une valeur par défaut ($text = "-").

Die Datei kann nicht geladen werden, da die Ausführung von Skripts auf diesem System deaktiviert ist.

La stratégie d'exécution de PowerShell bloque les scripts. L'assouplir seulement pour la session en cours :

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

... ist weder als Cmdlet, Funktion, Skriptdatei noch als ausführbares Programm erkannt

La commande n'existe pas sous Windows (par exemple une commande Linux). La correspondance se trouve au chapitre 25.

Le script ne trouve pas les fichiers avec caractères spéciaux

Utiliser -LiteralPath au lieu de -Path, pour que des caractères comme [ et ] ne soient pas lus comme un motif.
