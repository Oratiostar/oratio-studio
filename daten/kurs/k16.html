16.1 Grundbegriffe

  • Sketch – ein Arduino-Programm (Datei mit der Endung .ino)
  • setup() – läuft einmal beim Start
  • loop() – läuft danach immer wieder
  • Board / FQBN – die Boardbezeichnung, zum Beispiel arduino:avr:nano
  • Port – die USB-Schnittstelle, meist /dev/ttyUSB0 oder /dev/ttyACM0
  • Bibliothek (Library) – Fertigcode für ein Bauteil

16.2 Das erste Programm: Blinken

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

pinMode macht den Pin zum Ausgang, digitalWrite schaltet ihn an oder aus, delay(1000) wartet 1000 Millisekunden. Wenn die eingebaute LED blinkt, funktioniert die gesamte Kette: Programm, Compiler, Upload und Board.

16.3 Arduino CLI auf dem Raspberry Pi

Die alte Arduino-IDE 1.0 auf dem Pi hat bei mir Probleme gemacht: Die Bibliotheken Adafruit BusIO und GFX liefen nicht richtig, und die Deinstallation war schwierig (sie war mit „Pi Apps" installiert). Die bessere Lösung war arduino-cli, ein Programm für das Terminal.

Installation:

curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh
sudo mv bin/arduino-cli /usr/local/bin/
arduino-cli version

Board-Paket installieren:

arduino-cli core update-index
arduino-cli core install arduino:avr

Board suchen:

arduino-cli board list

Mein Nano-Klon erschien als /dev/ttyUSB0, aber als „Unbekannt". Das ist bei vielen Nano-Klonen normal.

Bibliotheken installieren:

arduino-cli lib install "Adafruit SSD1306"
arduino-cli lib install "Adafruit GFX Library"

Projekt anlegen, kompilieren, hochladen:

mkdir ~/OLED_Test
cd ~/OLED_Test
nano OLED_Test.ino
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old .
arduino-cli upload -p /dev/ttyUSB0 --fqbn arduino:avr:nano:cpu=atmega328old .

Der wichtige Trick mit dem Bootloader: Viele Nano-Klone brauchen :cpu=atmega328old (alter Bootloader). Wenn der Upload fehlschlägt, hilft die Variante ohne diesen Zusatz:

arduino-cli compile --fqbn arduino:avr:nano .
arduino-cli upload -p /dev/ttyUSB0 --fqbn arduino:avr:nano .

Der Punkt . am Ende bedeutet „der Sketch im aktuellen Ordner".

16.4 Ordnung: ein Ordner pro Projekt

Jedes Projekt bekommt seinen eigenen Ordner, und die .ino-Datei trägt denselben Namen wie der Ordner:

/home/oratio/
├── OLED_Test/
│   └── OLED_Test.ino
├── Blink_Test/
│   └── Blink_Test.ino
├── Uhr_Projekt/
│   └── Uhr_Projekt.ino
└── Wetterstation/
    └── Wetterstation.ino

Die Befehle zum Kompilieren und Hochladen bleiben immer gleich, solange dasselbe Board und derselbe Port benutzt werden. Nur der Ordner ändert sich:

cd ~/Uhr_Projekt
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old .
arduino-cli upload -p /dev/ttyUSB0 --fqbn arduino:avr:nano:cpu=atmega328old .

Erst bei einem anderen Board (ESP32, Uno, Mega) oder einem anderen Port (ttyUSB1) müssen die Befehle geändert werden.

16.5 Das Display OLED SSD1306 (128×64, I²C)

Verkabelung Nano ↔︎ OLED:

Display Arduino Nano
GND GND
VCC 5 V
SCL A5
SDA A4

Beispielprogramm:

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

void setup() {
  Wire.begin();

  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    while (true);
  }

  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);

  display.setCursor(0, 0);
  display.println("Hallo Oratio");
  display.setCursor(0, 15);
  display.println("Arduino Nano");

  display.display();
}

void loop() {
}

Die wichtigsten Befehle für das Display:

Befehl Wirkung
display.clearDisplay() Bildspeicher löschen
display.setTextSize(2) Schriftgröße
display.setCursor(x, y) Textposition in Pixeln
display.println("Text") Text schreiben
display.setRotation(1) Bild drehen (0–3)
display.display() alles zeichnen (ohne diesen Befehl bleibt das Display leer!)

Lektion „Display kaputt?": Wenn nichts zu lesen ist, ist das Display meist in Ordnung. Die Schrift ist nur zu klein (setTextSize(1)) und das Bild im Hochformat. Mit setRotation(1) und setTextSize(2) oder 3 wird der Text gut lesbar. Erst prüfen, ob die Software falsch eingestellt ist, bevor die Hardware verdächtigt wird.

16.6 Warum war das Display beim zweiten Mal leer?

Warum bleibt das Display manchmal leer? Der Zusammenhang ist: Der Bildspeicher des Displays wird mit clearDisplay() geleert, und erst display.display() überträgt ihn zum Bildschirm. Fehlt das, bleibt das Display leer, oder es zeigt noch etwas aus dem vorigen Programm.

16.7 Eine andere Bibliothek: U8g2

Wenn Adafruit-Bibliotheken Probleme machen, ist U8g2 eine Alternative, die oft ohne Adafruit GFX auskommt:

#include <Wire.h>
#include <U8g2lib.h>

U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0);

void setup() {
  u8g2.begin();
  u8g2.clearBuffer();
  u8g2.setFont(u8g2_font_ncenB08_tr);
  u8g2.drawStr(0, 20, "Hallo");
  u8g2.sendBuffer();
}

void loop() {}

16.8 Raspberry Pi und Arduino zusammenarbeiten lassen

Es gibt mehrere Möglichkeiten, einen Nano mit Display „klug" zu machen:

  1. Pi als Gehirn: Der Pi holt Uhrzeit, Wetter, CPU-Temperatur und IP und schickt sie per USB (seriell) an den Nano, der sie anzeigt. Wird der Pi abgezogen, kommen keine neuen Daten mehr.
  2. Nur einmal einstellen: Der Pi stellt die Uhr, danach läuft der Nano allein. Die Zeit geht aber nach einem Stromausfall verloren und driftet.
  3. Echtzeituhr (RTC, zum Beispiel DS3231): Der Nano behält die Zeit auch ohne Strom und ohne Pi. Das ist die richtige Lösung für eine eigenständige Uhr.

16.9 Programme ansehen und sichern: avrdude

Kann man ein Programm vom Arduino zurücksichern? Ja, mit avrdude:

avrdude -c arduino -p m328p -P /dev/ttyUSB0 -b 115200 -U flash:r:backup.hex:i    # auslesen
avrdude -c arduino -p m328p -P /dev/ttyUSB0 -b 115200 -U flash:w:backup.hex:i    # zurückschreiben

(Unter Windows heißt der Port COM3, auf dem Pi /dev/ttyUSB0.) Wichtig: Man bekommt nur die kompilierte Version (.hex), nicht den Quellcode (.ino). Sie reicht aus, um das Projekt auf einen anderen Arduino zu übertragen. Ist das Lock-Bit gesetzt, lässt sich der Chip nicht auslesen.
