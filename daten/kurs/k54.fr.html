Les erreurs Python s'appellent Traceback. Les lire par le bas : la dernière ligne est le type de l'erreur, au-dessus se trouvent le fichier et le numéro de ligne.

54.1 Indentation

IndentationError: unexpected indent

Une ligne est plus indentée que Python ne l'attend.

IndentationError: expected an indented block after function definition

Après def ...: (ou if, for, class), un bloc indenté manque. Mettre au moins pass.

IndentationError: unindent does not match any outer indentation level

L'indentation saute à une profondeur qui n'existe pas plus haut (par exemple 3 au lieu de 4 espaces).

TabError: inconsistent use of tabs and spaces in indentation

Tabulation et espaces sont mélangés. Règle : toujours 4 espaces. Dans l'éditeur, convertir les tabulations en espaces.

Cas particulier : si def run_oled_loop(self): est plus indentée que la fonction précédente, Python la prend pour une partie de la fonction précédente. Les méthodes d'une classe doivent être indentées exactement pareil. Un programme démarre alors apparemment « sans erreur », mais la fonction n'existe pas.

54.2 Syntaxe

SyntaxError: invalid syntax

Un caractère manque ou est faux : : en fin de ligne, parenthèse non fermée, = au lieu de ==. Regarder aussi la ligne précédente, car c'est souvent là que la parenthèse manque.

SyntaxError: f-string: single '}' is not allowed

Dans une f-string, { et } sont réservés aux variables. Si une accolade doit apparaître littéralement (par exemple dans une feuille de style CSS), il faut la doubler :

btn.setStyleSheet(f"""
    QPushButton {{
        background-color: {farbe};
        color: white;
    }}
""")

except en double

Deux blocs except qui interceptent la même chose, ou un try sans except : un try demande au moins un except ou finally, et l'erreur la plus spécifique vient avant la générale (except Exception).

54.3 Noms et variables

NameError: name 'xyz' is not defined

Le nom n'existe pas à cet endroit. Raisons :

  • Faute de frappe (btn_ok au lieu de btn_OK)
  • La variable est créée plus tard ou dans une autre fonction
  • Import manquant
  • self. manque : self.name au lieu de name pour des variables de classe

UnboundLocalError: cannot access local variable 'page'

Une variable est affectée dans une fonction et lue avant. Python la considère alors comme locale. Solution : lui affecter une valeur avant ou la passer en paramètre.

AttributeError: 'NoneType' object has no attribute 'setCurrentIndex'

L'objet est None : il n'a jamais été créé, ou la fonction n'a rien renvoyé. Vérifier si le widget (par exemple la ComboBox) a été créé avant avec self.xyz = QComboBox() et si le nom est correct.

AttributeError: 'OLED_TASK' object has no attribute 'screen4_interchange'

L'attribut manque à l'objet. Il n'a pas été créé dans __init__, ou le nom est écrit autrement. Ajouter l'attribut dans __init__.

IndexError: list assignment index out of range

On affecte une place de liste qui n'existe pas. Exemple : une liste de 3 entrées a les places 0, 1 et 2. liste[4] = ... ou liste[3] = ... échoue. Si on intègre une nouvelle (quatrième) page, il faut étendre toutes les listes : [0,0,0,0], [3.0,3.0,3.0,3.0], [True,True,True,True].

TypeError: ...

Une valeur a le mauvais type (texte au lieu de nombre) ou une fonction reçoit trop ou trop peu d'arguments. Lire précisément le message : il nomme la fonction et le nombre.

54.4 Fichiers et droits

PermissionError: [Errno 13] Permission denied: '...'

Le programme n'a pas le droit d'écrire le fichier, par exemple parce qu'il appartient à root (parce qu'il a été créé avec sudo). Changer le propriétaire : sudo chown oratio:oratio datei.

FileNotFoundError

Le fichier ou le dossier n'existe pas. Travailler avec un chemin absolu, par exemple via os.path.join(BASE_DIR, "datei.json") avec BASE_DIR = os.path.dirname(os.path.abspath(__file__)).

json.decoder.JSONDecodeError

Le fichier JSON est défectueux : virgule en trop ou en moins, guillemets manquants, accolade non fermée. Avec python3 -m json.tool datei.json, l'endroit apparaît.
