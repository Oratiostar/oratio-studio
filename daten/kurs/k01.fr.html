1.1 Qu’est-ce que le terminal ?

Le terminal est une fenêtre dans laquelle on donne à l’ordinateur des commandes textuelles. Sur le Raspberry Pi tourne Linux. Presque tout ce que l’on fait à la souris peut aussi se faire par commandes, et c’est souvent plus rapide et plus précis. On peut utiliser le terminal directement sur le Pi ou, via SSH, depuis un autre appareil.

Une commande a le plus souvent cette forme :

befehl  -optionen  ziel

Exemple :

ls -la /home/oratio

ls est la commande, -la sont des options (interrupteurs), /home/oratio est la cible.

1.2 Où suis-je ? Fichiers et dossiers

Commande Signification Exemple
pwd affiche le dossier actuel pwd
ls liste les fichiers ls
ls -la tout, y compris les fichiers cachés, avec les détails ls -la
cd Ordner changer de dossier cd Projekte
cd .. remonter d’un niveau cd ..
cd ~ aller dans le dossier personnel cd ~
mkdir Name créer un dossier mkdir Test
touch datei.txt créer un fichier vide touch test.txt
cat datei.txt afficher le contenu d’un fichier cat test.txt
cp a.txt b.txt copier cp datei.txt kopie.txt
mv a.txt Ordner/ déplacer ou renommer mv datei.txt Ordner/
rm datei.txt supprimer (définitivement, pas de corbeille !) rm datei.txt

Important : rm supprime immédiatement et sans confirmation. Il n’y a pas de corbeille. Un dossier se supprime avec rm -r dossier. La commande rm -rf est particulièrement dangereuse, car elle ne demande jamais rien.

Le caractère ~ désigne le dossier personnel, chez moi /home/oratio. La touche Tab complète automatiquement les noms de fichiers, et les flèches haut/bas ramènent les commandes précédentes.

1.3 Modifier des fichiers avec nano

nano est l’éditeur de texte le plus simple du terminal. J’en ai constamment besoin.

nano ~/.bashrc

Utilisation de nano (les raccourcis clavier sont affichés en bas de la fenêtre) :

  • Enregistrer : Ctrl + O, puis Entrée
  • Quitter : Ctrl + X
  • Quand nano demande après l’enregistrement : Entrée confirme le nom du fichier.

Quand on colle un long code dans le terminal, il peut être très long à effacer ensuite. Dans nano, Ctrl + K supprime une ligne entière.

1.4 Obtenir de l’aide

man ls          # ausführliche Anleitung (Beenden mit q)
ls --help       # Kurzhilfe
history         # alle bisherigen Befehle
history | grep wlr    # nur Befehle, in denen "wlr" vorkommt
!!              # den letzten Befehl wiederholen

1.5 La barre verticale : le pipe

Le caractère | (le pipe) envoie la sortie de la première commande à la seconde. Je l’ai utilisé en permanence :

ps aux | grep python         # Prozesse anzeigen, aber nur die mit "python"
dmesg | tail                 # die letzten Kernel-Meldungen
wlr-randr | grep Scale       # nur die Zeile mit der Skalierung

1.6 Enchaîner des commandes

Caractère Signification
&& la deuxième commande seulement si la première a réussi
; la deuxième commande dans tous les cas
& à la fin lancer en arrière-plan (p. ex. kanshi &)
> écrire la sortie dans un fichier (écrase)
>> ajouter la sortie à un fichier 
sudo apt update && sudo apt upgrade -y
echo "Text" >> datei.txt

1.7 Une erreur typique : le caractère en trop

Une faute de frappe typique : j’ai saisi <wlr-randr --output HDMI-A-1 --scale 3. Le < au début de la commande signifie dans le shell : « lis le contenu d’un fichier ». Le shell indique alors que le fichier est introuvable. À retenir : taper les commandes exactement, chaque caractère compte. Sous Linux, les majuscules et minuscules comptent aussi.
