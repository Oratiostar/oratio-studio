Python-Fehler heißen Traceback. Lies ihn von unten: Die letzte Zeile ist die Art des Fehlers, darüber steht Datei und Zeilennummer.

54.1 Einrückung

IndentationError: unexpected indent

Eine Zeile ist weiter eingerückt, als Python erwartet.

IndentationError: expected an indented block after function definition

Nach def ...: (oder if, for, class) fehlt ein eingerückter Block. Mindestens pass einsetzen.

IndentationError: unindent does not match any outer indentation level

Die Einrückung springt auf eine Tiefe, die es oben nicht gibt (zum Beispiel 3 statt 4 Leerzeichen).

TabError: inconsistent use of tabs and spaces in indentation

Tabulator und Leerzeichen sind gemischt. Regel: immer 4 Leerzeichen. Im Editor Tabs in Leerzeichen umwandeln.

Sonderfall: Steht def run_oled_loop(self): weiter eingerückt als die Funktion davor, hält Python sie für einen Teil der vorigen Funktion. Methoden einer Klasse müssen genau gleich weit eingerückt sein. Ein Programm startet dann scheinbar „ohne Fehler", aber die Funktion existiert nicht.

54.2 Syntax

SyntaxError: invalid syntax

Ein Zeichen fehlt oder ist falsch: : am Zeilenende, Klammer nicht geschlossen, = statt ==. Die Zeile davor auch ansehen, denn oft fehlt dort die Klammer.

SyntaxError: f-string: single '}' is not allowed

In einem f-String sind { und } für Variablen reserviert. Soll eine Klammer buchstäblich erscheinen (zum Beispiel in einem CSS-Stylesheet), muss man sie verdoppeln:

btn.setStyleSheet(f"""
    QPushButton {{
        background-color: {farbe};
        color: white;
    }}
""")

Doppeltes except

Zwei except-Blöcke, die dasselbe abfangen, oder ein try ohne except: Ein try braucht mindestens ein except oder finally, und der spezifischere Fehler steht vor dem allgemeinen (except Exception).

54.3 Namen und Variablen

NameError: name 'xyz' is not defined

Der Name existiert an dieser Stelle nicht. Gründe:

  • Tippfehler (btn_ok statt btn_OK)
  • Variable wird später oder in einer anderen Funktion angelegt
  • Import fehlt
  • self. fehlt: self.name statt name bei Klassenvariablen

UnboundLocalError: cannot access local variable 'page'

Eine Variable wird in einer Funktion zugewiesen und zugleich vorher gelesen. Python hält sie dann für lokal. Lösung: vorher einen Wert zuweisen oder als Parameter übergeben.

AttributeError: 'NoneType' object has no attribute 'setCurrentIndex'

Das Objekt ist None: Es wurde nie angelegt, oder die Funktion lieferte nichts zurück. Prüfen, ob das Widget (zum Beispiel die ComboBox) vorher mit self.xyz = QComboBox() erzeugt wurde und ob der Name stimmt.

AttributeError: 'OLED_TASK' object has no attribute 'screen4_interchange'

Dem Objekt fehlt das Attribut. Es wurde in __init__ nicht angelegt, oder der Name ist anders geschrieben. Das Attribut in __init__ ergänzen.

IndexError: list assignment index out of range

Man weist einem Listenplatz zu, der nicht existiert. Beispiel: Eine Liste mit 3 Einträgen hat die Plätze 0, 1 und 2. liste[4] = ... oder liste[3] = ... scheitert. Wird eine neue (vierte) Seite eingebaut, müssen alle Listen erweitert werden: [0,0,0,0], [3.0,3.0,3.0,3.0], [True,True,True,True].

TypeError: ...

Ein Wert hat den falschen Typ (Text statt Zahl) oder eine Funktion bekommt zu viele oder zu wenige Argumente. Meldung genau lesen: Sie nennt die Funktion und die Anzahl.

54.4 Dateien und Rechte

PermissionError: [Errno 13] Permission denied: '...'

Das Programm darf die Datei nicht schreiben, zum Beispiel weil sie root gehört (weil sie mit sudo angelegt wurde). Besitzer ändern: sudo chown oratio:oratio datei.

FileNotFoundError

Die Datei oder der Ordner existiert nicht. Mit absolutem Pfad arbeiten, zum Beispiel über os.path.join(BASE_DIR, "datei.json") mit BASE_DIR = os.path.dirname(os.path.abspath(__file__)).

json.decoder.JSONDecodeError

Die JSON-Datei ist fehlerhaft: Komma zu viel oder zu wenig, Anführungszeichen fehlen, Klammer nicht geschlossen. Mit python3 -m json.tool datei.json zeigt sich die Stelle.
