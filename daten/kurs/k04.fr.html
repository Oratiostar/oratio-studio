Ces outils m’ont aidé à trouver le bon endroit dans de gros fichiers. C’était souvent la clé de la solution.

4.1 grep – chercher du texte

grep -n "def open_kanshi_dialog" app_ui_pi_tools.py   # mit Zeilennummer
grep -Ri rotation .                                    # rekursiv, ohne Groß/Klein
grep -E '^(autologin-user|autologin-session)' /etc/lightdm/lightdm.conf
  • -n affiche le numéro de ligne
  • -i ignore la casse
  • -R cherche aussi dans les sous-dossiers
  • -E autorise les motifs étendus

Voici comment j’ai trouvé la rotation de l’OLED dans le code Freenove : grep -Ri oled . a montré tous les endroits où l’écran est piloté.

4.2 find – trouver des fichiers

find ~/Desktop -name demo
find . -iname "*pico*" -o -iname "*.pio"
find build -type f -name "*.uf2"

-name cherche par nom, -iname sans tenir compte de la casse, -type f seulement les fichiers. Avec cela, j’ai trouvé les fichiers Pico et le firmware .uf2.

4.3 sed – afficher et remplacer des lignes

sed -n '390,445p' app_ui_pi_tools.py            # nur Zeilen 390 bis 445 anzeigen
sed -i 's/\.red/.r/g; s/\.green/.g/g; s/\.blue/.b/g' arcade.cc   # ersetzen

sed -n 'A,Bp' affiche un extrait d’un fichier. C’est pratique quand une erreur indique un numéro de ligne : on voit exactement l’endroit. sed -i modifie directement le fichier, il faut donc d’abord en faire une copie.

4.4 head, tail, awk, wc

head -n 20 datei.txt          # erste 20 Zeilen
tail -n 20 datei.txt          # letzte 20 Zeilen
tail -f datei.log             # live mitlesen
wlr-randr | grep "Scale:" | head -n1 | awk '{print $2}'   # nur die Zahl

Le dernier exemple vient de mon script de surveillance : grep trouve la ligne avec l’échelle, head -n1 prend la première, awk '{print $2}' affiche le deuxième mot.
