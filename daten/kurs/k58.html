Wenn die Meldung nicht im Lexikon steht, hilft dieses Vorgehen (Kapitel 47 erklärt es ausführlich):

  1. Meldung wörtlich lesen, letzte Zeile zuerst.
  2. Datei und Zeile aus der Meldung öffnen.
  3. Was wurde zuletzt geändert? Die letzte Änderung rückgängig machen oder einzeln prüfen.
  4. Eingrenzen: Das Programm im Terminal starten, einen kleinen Test schreiben, Teile auskommentieren.
  5. Umgebung prüfen: Richtiger Ordner (pwd), richtiger Benutzer, richtige Python-Umgebung, richtiges Board, richtiger Port.
  6. Hardware zuletzt verdächtigen: Zuerst Software und Einstellungen, dann Kabel, dann Bauteil.
  7. Lösung dokumentieren: Meldung, Ursache und Befehl in eine eigene Notizdatei schreiben.
Typische Meldung Erste Prüfung
not found Name und Pfad stimmen? Installiert?
Permission denied ls -l, Besitzer, chmod, sudo
not declared Reihenfolge, Include, Schreibweise
IndentationError Leerzeichen statt Tabs, gleiche Tiefe
No such file Pfad absolut angeben
Exec format error Architektur (uname -m)
Display bleibt schwarz Adresse, Pins, display.display()
Upload scheitert Port, Kabel, BOOT-Taste, Bootloader
