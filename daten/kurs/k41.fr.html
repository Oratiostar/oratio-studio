41.1 De quoi il s’agit

Dans le projet A et dans la première forme de B, le glisser est assemblé à partir d'événements de souris : mousePressEvent retient le début, mouseMoveEvent déplace une image, mouseReleaseEvent décide. Dans cette variante, c'est Qt lui-même qui se charge du glisser avec QDrag, QMimeData et dropEvent. Le comportement est le même : sur une place occupée = échanger, sur une place vide = l'ancienne place reste vide, changement de page au bord (0,75 s, puis 1,1 s), trou dans le dock, verre dépoli sur l'application cible.

Nouveau grâce à cela : Échap annule le glisser (l'application reste à sa place). Relâcher en dehors de la fenêtre signifie annulé.

41.2 Le déroulement en quatre étapes

(d'après la description dans Parts/view_dnd.py)

  1. La tuile ou le symbole du dock signale « tiré assez loin » (signal dragRequested). La vue démarre _start_tile_drag ou _start_dock_drag.
  2. Là, un QDrag est lancé avec l'image flottante. QDrag.exec_() tourne jusqu'au relâchement ou à l'annulation. Pendant ce temps, les minuteurs et les animations continuent normalement.
  3. Toute la vue est la cible. dragEnterEvent, dragMoveEvent, dragLeaveEvent et dropEvent reçoivent la position du pointeur et montrent l'aperçu.
  4. Après exec_(), _drag_done ou _dock_drag_done place l'application (relâchée) ou annule tout (abandon).

41.3 Le cœur en quelques lignes

from PyQt5.QtCore import QMimeData, Qt
from PyQt5.QtGui import QDrag

def _run_qt_drag(self, image, hotspot, mime_type, payload):
    """Kehrt erst zurück, wenn losgelassen oder abgebrochen wurde."""
    data = QMimeData()
    data.setData(mime_type, payload)      # welche Art Ding wird gezogen (Kachel, Dock-Symbol)
    drag = QDrag(self)
    drag.setMimeData(data)
    drag.setPixmap(image)                 # das schwebende Bild
    drag.setHotSpot(hotspot)              # wo im Bild "angefasst" wurde
    return drag.exec_(Qt.MoveAction)

Pour que la vue accepte des glissements, elle doit appeler setAcceptDrops(True) et redéfinir les quatre méthodes d'événement. Les noms MIME pour la tuile et le dock se trouvent dans Parts/consts.py (MIME_TILE, MIME_DOCK, et MIME_CC pour la fenêtre de contrôle).

41.4 Comparaison avec la solution par événements de souris

Annulation avec Échap à construire soi-même offerte
Relâcher en dehors à traiter soi-même offert
Image flottante widget maison qui suit le pointeur setPixmap
Les animations continuent-elles ? ja oui (exec_ a sa propre boucle d'événements)

Là où le glisser-déposer Qt ne convient pas : pour redimensionner les tuiles dans la fenêtre de contrôle (coin inférieur droit), l'ancienne logique de souris reste, parce que ce n'est pas le glissement d'un objet, mais une modification.

Dans la même variante, le fichier de 10 700 lignes oratio_menu.py a été découpé dans Oratio_Menu/Parts/ (rien changé au contenu, seulement déplacé) :
