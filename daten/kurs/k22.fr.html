Faut-il un logiciel spécial pour apprendre Python ? Non, un simple éditeur comme Geany suffit. Voici les bases, avec des exemples tirés d'un vrai projet : ouvrir des fichiers, chercher des fonctions, trouver des erreurs, modifier des variables, intégrer des listes déroulantes, changer des mises en page et lancer des programmes.

22.1 Le premier programme

  1. Ouvrir Geany, créer un nouveau fichier.
  2. Écrire : print("Hallo Oratio")
  3. Enregistrer sous hello.py. L'extension .py est importante, elle indique à Geany que c'est du Python.
  4. Exécuter : dans Geany via le menu Construire → Exécuter, ou cliquer sur la petite icône de fusée ou d'avion en papier. Dans le terminal : python3 hello.py.

22.2 Les éléments les plus importants

Variables

name = "Oratio"
slot = 5
scale = 3.0
aktiv = True

Textes avec valeurs intégrées (f-string)

print(f"{self.app_name} -> {button.app_name}")

Conditions

if index == 0:
    self.screen1_display_time_label.setStyleSheet(btn_style)
elif index == 1:
    self.screen2_display_time_label.setStyleSheet(btn_style)
else:
    pass

elif signifie « sinon si ». pass signifie « ne rien faire ». En ajoutant une quatrième page, il a fallu ajouter un autre elif index == 3: à chaque endroit. C'est une erreur fréquente : on ne modifie qu'un seul des endroits.

Boucles

for app in apps:
    row = app["row"]
    col = app["col"]

Fonctions

def run_script(self, filename):
    subprocess.Popen(["python3", filename])

Classes : une fenêtre ou une page est une classe. self signifie « cet objet ».

class ScriptsTab(QWidget):
    def __init__(self, width, height):
        super().__init__()

Intercepter les erreurs

try:
    subprocess.Popen(["python3", filename])
except Exception as e:
    print(e)

22.3 L’indentation fait partie du langage

En Python, c'est l'indentation qui détermine ce qui appartient à quoi. Cela conduit à une erreur étrange : si def run_oled_loop(self): est plus indenté que def oled_ui_4_show(self):, Python considère la deuxième fonction comme faisant partie de la première. Correct :

def oled_ui_3_show(self, pi_temperature, pi_duty):
    ...

def oled_ui_4_show(self):
    ...

def run_oled_loop(self):
    ...

Les deux def doivent être exactement l'un sous l'autre. Dans Geany, cliquer dans la ligne et vérifier que le d de def est dans la même colonne pour les deux.

22.4 JSON – les réglages dans un fichier

Mon Control Center enregistre les applications et les réglages dans des fichiers JSON. JSON est un format texte pour des données structurées :

{
    "id": "cpu_temp",
    "name": "CPU Temp",
    "tool": "cpu_temp",
    "slot": 5,
    "category": "system",
    "color": "#404040",
    "icon": "Pi_Tools/Icons/cpu_temp.png"
}

Lire et écrire en Python :

import json

with open("oratio_apps.json", "r") as f:
    apps = json.load(f)

for app in apps:
    app["slot"] = app["row"] * 6 + app["col"]

with open("oratio_apps_slot.json", "w") as f:
    json.dump(apps, f, indent=4)

Règles : en JSON, les textes sont entre guillemets doubles, il y a une virgule entre les entrées, mais aucune après la dernière. Une seule virgule en trop empêche le programme de démarrer. Cela m'est arrivé plusieurs fois (« Mon application ne démarre plus »).

22.5 Messages d’erreur typiques en Python

Message Signification Exemple
NameError: name 'screen4_config' is not defined une variable n'a jamais été créée screen3_config = ...get('screen4') figurait en double, screen4_config manquait
UnboundLocalError: cannot access local variable 'page' la variable est utilisée avant d'avoir une valeur lignes avec page = ... commentées, mais if page != ... est resté
IndentationError indentation erronée fonction trop indentée
SyntaxError code invalide deux except Exception as e: à la suite
Permission denied pas de droits script sans chmod +x

Comment trouver de telles erreurs : le message d'erreur indique le fichier et le numéro de ligne. Avec sed -n '430,445p' datei.py, cet endroit précis s'affiche. Avec grep -n "page" datei.py, on voit toutes les utilisations.

22.6 Déboguer avec print

Quand un bouton « ne fait rien », on vérifie pas à pas :

  1. Le bouton est-il relié à la fonction ? (self.btn5.clicked.connect(self.open_kanshi_dialog))
  2. La fonction existe-t-elle seulement ? (grep -n "def open_kanshi_dialog" datei.py)
  3. Est-elle appelée ? Écrire en première ligne de la fonction : print("Kanshi geklickt") et lancer le programme dans le terminal avec python3 app_ui.py. Si le texte apparaît, la connexion est bonne et l'erreur se trouve à l'intérieur de la fonction.
