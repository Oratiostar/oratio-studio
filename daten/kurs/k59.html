59.1 Welcher Raspberry Pi, welches System?

Pi 3 Pi 4 Pi 5
Prozessor schwächer deutlich schneller deutlich schneller als der Pi 4
Speicher 1 GB 2 bis 8 GB 4, 8 oder 16 GB
Schnittstelle für SSD nur USB 2 USB 3 USB 3 und PCIe (NVMe über Adapter)
Netzteil 5 V / 2,5 A 5 V / 3 A 5 V / 5 A
Kühlung meist nicht nötig empfohlen Lüfter empfohlen
  • 32 Bit gegen 64 Bit: Auf Pi 4 und 5 nimmt man 64 Bit. Viele Programme (zum Beispiel aktuelle VS-Code- oder Arduino-Versionen) gibt es nur noch dafür. 32 Bit ist nur für sehr alte Geräte sinnvoll.
  • Lite, Desktop oder Full: Lite hat keine Oberfläche (Server, Terminal), Desktop hat die grafische Oberfläche, Full bringt zusätzlich viel Software mit. Zum Lernen reicht Desktop.
  • Bookworm und Trixie: Namen der Debian-Versionen (12 und 13). Trixie ist neuer. Beide nutzen standardmäßig Wayland mit dem Fenstermanager labwc.
  • SD-Karte in ein anderes Modell stecken: Meist geht das, solange das System für beide Modelle gebaut ist. Ein System, das für Pi 5 gebaut ist, läuft nicht auf einem Pi 3 und umgekehrt.

59.2 Image auf eine SD-Karte schreiben

  1. Raspberry Pi Imager installieren (sudo apt install rpi-imager oder von der Webseite) und starten.
  2. Betriebssystem wählen, Speichermedium wählen, Einstellungen (Benutzername, WLAN, SSH) eintragen.
  3. Schreiben und warten.

Bei einer fertigen Datei mit der Endung .xz ist Auspacken unnötig: Der Imager liest sie direkt (Eigenes Image wählen). Zum Auspacken im Terminal: unxz datei.img.xz.

Andere Programme: balenaEtcher (Windows, Mac, Linux), Win32 Disk Imager (Windows, zum Schreiben und Sichern eines Images), dd im Terminal (schnell, aber ein falscher Zielname überschreibt das falsche Laufwerk). Ein Image von einem Laufwerk ziehen geht mit Win32 Disk Imager oder dd.

59.3 GPIO-Nummerierung

Ein Pin hat zwei Nummern:

Nummer Bedeutung
Physische Pinnummer (1 bis 40) Position auf der Stiftleiste
BCM-Nummer (GPIO 17, GPIO 18 ...) Name des Prozessor-Anschlusses

Die Abbildungen im Internet unterscheiden sich, weil manche die physische und manche die BCM-Nummer beschriften. In Python benutzt man in der Regel die BCM-Nummer. Immer zuerst prüfen, welche Nummerierung gemeint ist.

59.4 SSH: Wozu?

SSH öffnet ein Terminal auf dem Pi von einem anderen Gerät aus (PC, Handy). Damit lassen sich Befehle eingeben, Dateien kopieren (scp, sftp) und den Pi ohne Bildschirm betreiben (headless). Aktivieren: sudo raspi-config → Interface Options → SSH. Verbinden: ssh oratio@<IP-Adresse>; die IP zeigt hostname -I.

59.5 SSD, NVMe und Adapter

  • NVMe-SSD am Pi 5: Über einen M.2-HAT an der PCIe-Schnittstelle. Der Pi 5 arbeitet standardmäßig mit PCIe Gen 2 (etwa 500 MB/s) und kann mit dtparam=pciex1_gen=3 auf Gen 3 gestellt werden (nicht offiziell garantiert).
  • Nur eine PCIe-Leitung: Mehr Geräte an einer Leitung gehen nur über einen PCIe-Switch, und sie teilen sich die Geschwindigkeit.
  • Keys beim M.2-Stecker: SSDs mit M-Key (eine Kerbe) sind NVMe. Eine SSD mit zwei Kerben (B+M) ist oft eine SATA-SSD, die ein NVMe-Adapter nicht ansteuert. Auf das Typenschild achten.
  • USB-Gehäuse: Wenn eine SSD am USB-Adapter 0 B zeigt, siehe Kapitel 56.3.
  • Boot von SSD: sudo raspi-config → Advanced Options → Boot Order (Kapitel 26.7).
  • Wo schaue ich nach Werten? lsblk (Laufwerke), sudo fdisk -l (der Schalter -l bedeutet list), sudo nvme list.

59.6 Mehr Zubehör für den Pi 5

  • HATs sind Aufsteckplatinen, zum Beispiel für SSD, KI oder Display. Unten montierte HATs (HAT+ und ähnliche) nutzen den PCIe-Anschluss.
  • NPU (Neural Processing Unit) ist ein Beschleuniger für KI-Aufgaben (Bilder, Sprache). Er ist kein Ersatz für den Prozessor, sondern eine Zusatzkarte, etwa der AI HAT.
  • Compute Module ist der Pi ohne Anschlüsse, zum Einbau in eigene Geräte. Der normale Pi hat alle Buchsen auf der Platine.
  • Home Assistant OS ist ein System für Smart Home, das über den Browser bedient wird.
  • Controller verbinden: Per Bluetooth (bluetoothctl) oder per USB. Unter Batocera/RetroPie gibt es eine eigene Controller-Zuordnung.

59.7 Temperatur und Last

  • Der Pi 5 liegt im Normalbetrieb bei etwa 40 bis 60 °C. Ab etwa 80 °C regelt er die Leistung herunter.
  • Temperatur: vcgencmd measure_temp. Zustand der Spannung und der Drosselung: vcgencmd get_throttled.
  • CPU voll? top oder htop zeigt, welches Programm die Leistung braucht. Beenden mit kill PID.

59.9 Terminal: Bash, sh und Skripte

  • Shell ist das Programm, das die Eingaben liest. Bash („Bourne Again SHell", ein Wortspiel auf den Vorgänger Bourne Shell) ist die übliche Shell unter Linux.
  • Eine Datei xyz.sh ist ein Shell-Skript: eine Textdatei mit Befehlen. Sie läuft in Bash, wenn die erste Zeile #!/bin/bash ist.
  • Ausführbar machen: chmod +x xyz.sh, starten mit ./xyz.sh.
  • alias name='befehl' in ~/.bashrc legt eine Abkürzung an, source ~/.bashrc lädt sie neu.
  • cd und sudo: cd wechselt den Ordner, sudo führt einen Befehl mit Administratorrechten aus. Es sind zwei völlig verschiedene Dinge.

59.10 Anzeigen

  • KMS (dtoverlay=vc4-kms-v3d in /boot/firmware/config.txt) ist der moderne Grafiktreiber. Die Datei wird mit sudo nano /boot/firmware/config.txt bearbeitet, Änderungen gelten nach dem Neustart.
  • Full HD gegen 4K: 4K hat viermal so viele Pixel. Bei Skalierung 2 wirkt 4K wie Full HD, nur schärfer. Der Pi 4 schafft 4K bei 60 Hz mit einem Bildschirm (mit zwei 4K-Bildschirmen je 30 Hz), der Pi 5 schafft 4K bei 60 Hz auch mit zwei Bildschirmen.
  • Bildschirm drehen: wlr-randr --output HDMI-A-1 --transform 180.
  • Anzeige auf dem Handy: Über VNC (Raspberry Pi Connect oder RealVNC) oder per Bildschirm-Streaming. Das ist der offizielle Weg ohne Zusatzhardware: Raspberry Pi Connect.
  • HDMI-Signal: Ein Bild besteht aus Pixeln, jeder Pixel aus drei Farbwerten (Rot, Grün, Blau, je 8 Bit). Diese Werte werden als Folge von Einsen und Nullen über mehrere Leitungspaare übertragen. 4K bei 60 Hz braucht ein passendes Kabel (HDMI 2.0).
  • Display mit eigenem Anschluss (DSI, GPIO): Prüfe, ob das Display einen HDMI- oder einen SPI-/DSI-Eingang hat. Für Touch braucht es zusätzlich eine USB- oder I²C-Verbindung und meist 5 V Versorgung.
