Ce chapitre est un ouvrage de référence : pour chaque fonction, il indique où la trouver à l'écran, quel fichier la contient et quel fichier de réglages elle crée. Qui veut reconstruire une fonction trouve ici les briques ; le guide général de construction soi-même se trouve au chapitre 39.

Toujours le même schéma (c'est ainsi que naît chaque nouvelle fonction) :

  1. Un nouveau fichier dans Oratio_Menu/ avec la logique et la fenêtre.
  2. Une ligne dans Fenster/zentrale.py (pour qu'elle apparaisse dans la liste des réglages).
  3. Une entrée dans suche.py (pour que la loupe la trouve).
  4. Un fichier JSON dans Json/, qui naît de lui-même à la première modification.
  5. Facultatif : un lancement dans Ansicht/leiste.py si quelque chose doit tourner en arrière-plan.

38.1 Centre de notifications (cloche)

  • Où : cloche en haut à droite (à gauche du pinceau). Toucher ouvre la liste, chaque notification peut être supprimée individuellement, en bas « Tout effacer ». Nombre rouge = non lu.
  • Bannière : une nouvelle notification glisse comme une petite bannière de verre sous la barre et ressort après environ 5 s.
  • Ne pas déranger : pas de bannière, pas de point rouge ; les notifications arrivent quand même dans la liste.
  • Arrivent d'elles-mêmes : minuteur et réveil, sauvegarde terminée ou échouée, mise à jour terminée, « Le Pi est chaud » (à partir de 80 °C CPU, nouveau message seulement après refroidissement sous 74 °C).
  • Masquer : réglages du menu → En haut à droite → « Cloche (notifications) ».
  • Notification personnelle depuis une application ou un script :
from Oratio_Menu import mitteilungen
mitteilungen.post("Titel", "Text", app="Name", level="ok")   # level: info, ok, warn, error

Les applications dans Oratio_Menu/Apps/... peuvent le faire directement. Sinon, d'abord sys.path.insert(0, <dossier du projet>). Une erreur dans cette ligne n'arrête jamais l'application.

  • Fichier : Oratio_Menu/mitteilungen.py ; enregistré dans Json/oratio_mitteilungen.json (les 60 dernières).

Une erreur qui se cachait : dans le fichier de langue française, 108 textes avec des valeurs insérées (« Page 3 », « 5 min », « Code d'erreur 2 ») affichaient un \1 au lieu de la valeur. Exactement ces 108 lignes ont été corrigées. Leçon : regarder une fois dans chaque langue les textes avec marqueurs de place, avec la valeur insérée.

38.2 Recherche (loupe)

  • Où : loupe en haut à droite, tout à gauche dans le groupe de symboles. Le champ de saisie est immédiatement prêt.
  • Trouve : applications (toucher lance l'application), réglages (toucher ouvre la fenêtre correspondante), calculs, commandes de l'Oratio Toolbox (toucher bascule vers la Toolbox, la recherche y est remplie).
  • Calculer : 12*7, (3+4)^2, 15% von 80, sqrt(81), 5-3. La lettre x n'est pas un calcul, mais × et ÷ fonctionnent. Toucher le résultat le copie.
  • Les fautes de frappe sont pardonnées : « brwsr » trouve « Browser », « hinterg » trouve « Hintergrund ändern » ; les trémas n'ont pas d'importance (ae/ä/a).
  • Sélection : flèche haut/bas, Entrée.
  • Rendre un nouveau réglage trouvable : dans Oratio_Menu/suche.py, ajouter une ligne dans la liste EINSTELLUNGEN (nom, mots de recherche, fonction).

38.3 Réglages style téléphone

  • Où : toucher la roue dentée tout à droite de la barre en haut, la barre se déploie, première entrée « Réglages ». Ou loupe → « einstellungen ».
  • Structure : en haut un champ de recherche, dessous des groupes avec des symboles colorés : Connexions (WLAN, Bluetooth, microphone), Notifications & contrôle, Apparence, Applications & pages, Système. À droite figure, quand c'est utile, la valeur actuelle.
  • Utilisation : toucher une ligne ouvre la fenêtre correspondante à droite, toucher de nouveau la ferme.
  • Fichier : Fenster/zentrale.py (une liste de lignes ; chaque nouvelle fonction s'y inscrit).

38.4 Historique (diagrammes à long terme)

  • Où : roue dentée → Réglages → Système → « Historique (diagrammes) », ou loupe → « verlauf ».
  • Quoi : dès le démarrage, le menu écrit en arrière-plan toutes les 30 s des valeurs de mesure : température du CPU, charge du CPU, RAM, vitesse du ventilateur (seulement si le Pi la signale – Pi 5 avec refroidisseur actif), réseau descendant/montant. En haut on choisit 1 h / 6 h / 1 jour / 1 semaine. Pour chaque grandeur, un diagramme avec « maintenant / moyenne / min / max » ; la souris dessus montre l'heure et la valeur.
  • Stockage : Json/oratio_verlauf.csv (point-virgule, virgule comme séparateur décimal ; Excel et LibreOffice l'ouvrent directement). Le menu supprime lui-même les valeurs de plus de 8 jours.
  • Bon à savoir : une lacune dans le diagramme signifie que le menu ne tournait pas durant ce temps. Après l'installation, il faut une ou deux minutes avant les premiers points.
  • Fichier : Oratio_Menu/verlauf.py.
  • Différence avec le Labor : le Labor (38.5) montre des valeurs en direct sur des minutes ; l'historique tourne en permanence en arrière-plan sur des jours.

38.5 Labo (poste de mesure)

Fichier : Oratio_Menu/Apps/Oratio_Labor/oratio_labor.py. Une application à sept onglets :

Onglet Ce qu'il sait faire Nécessite
Pins les 40 broches en image : vert = haut (3,3 V), sombre = bas, anneau bleu = sortie, anneau violet = fonction spéciale (I2C, UART, SPI). Toucher une broche : lire, entrée/sortie, haut/bas, pull-up/pull-down. Les broches occupées ne sont modifiées par l'application qu'après une seconde confirmation pinctrl (fourni avec Raspberry Pi OS)
I2C Scanner le bus, adresses avec ce qui s'y trouve le plus souvent (0x3C OLED, 0x76 BME280 …). « UU » = occupée par un pilote i2c-tools, I2C activé dans la configuration du Pi
Mesurer pour chaque grandeur un diagramme en direct (1 / 5 / 30 min) : température du CPU, charge du CPU, RAM, fréquence du CPU, capteurs 1-Wire (DS18B20, apparaissent d'eux-mêmes si dtoverlay=w1-gpio figure dans config.txt), tension de l'alimentation et du 3,3 V (Pi 5, via vcgencmd). « Enregistrer » écrit un CSV dans ~/Oratio_Messungen/ –
Série moniteur série pour ESP32, Arduino, GPS, adaptateur USB-UART python3-serial ; groupe dialout
Logique mini analyseur logique : jusqu'à 4 broches GPIO, enregistrer 1/5/20 s ; fronts, fréquence, rapport cyclique. Fiable jusqu'à quelques dizaines de kHz python3-lgpio
PWM servo (500–2500 µs, 50 Hz) ou PWM (fréquence, rapport cyclique) sur GPIO 12/13/18/19/17 python3-lgpio
Capteurs 22 capteurs à consulter (BME280, DS18B20, MPU6050, INA219, HC-SR04 …) avec câblage, adresse, logiciel ; « Chercher sur le bus » vérifie via i2cdetect –
Calculatrice code couleur, ohm/puissance, résistance série de LED (avec la valeur E12/E24 la plus proche), diviseur de tension, filtre RC –

Notation dans toutes les calculatrices : 4,7k, 4k7, 10u, 100n, 2.2M.

Utiliser ainsi l'onglet Série : brancher l'appareil en USB → « Rechercher à nouveau » → choisir le port (par ex. /dev/ttyUSB0 ou /dev/ttyACM0) → choisir la vitesse en bauds (doit correspondre au programme de l'appareil, souvent 115200) → bouton vert « Connecter ». En bas, taper une commande et Entrée ; à côté la fin de ligne (Aucune / \n / \r\n ; beaucoup d'appareils veulent \n). « Diagramme » trace les nombres des lignes sous forme de courbe en direct (jusqu'à 4 canaux ; format temp:23.5,hum:40 ou 23.5 40 7). « Enregistrer » sauvegarde avec l'heure dans ~/Oratio_Messungen/seriell_<heure>.csv.

  • Message « Permission manquante » : sudo usermod -aG dialout $USER, puis se reconnecter une fois ou redémarrer.
  • L'Arduino/ESP32 redémarre à la connexion : normal (le signal DTR déclenche une réinitialisation).

Règles de sécurité figurant dans l'onglet Labor et valables pour le montage : les entrées ne supportent que 3,3 V. Ne jamais alimenter servos et moteurs par le Pi, alimentation séparée, relier les GND.

38.6 Écran de verrouillage

  • Où : roue dentée → Réglages → Système → « Écran de verrouillage ». Rapide : loupe → « sperre ».
  • Apparence : grande horloge, date et les dernières notifications non lues au-dessus de l'image floue du menu.
  • Déverrouiller : sans code, un toucher ou une touche ; avec code, le pavé numérique (utilisable aussi au clavier). Mauvais code : secousse ; après 5 essais ratés, pause de 30 s.
  • Réglages : « Verrouiller maintenant », « Verrouiller automatiquement après inactivité » (Désactivé / 1 / 5 / 15 / 30 min), définir/modifier/supprimer le code (4–8 chiffres), interrupteur « Notifications sur l'écran de verrouillage ».
  • Fichier : Oratio_Menu/sperre.py ; réglages dans Json/oratio_sperre.json (le code n'y figure que sous forme de somme de contrôle). Code oublié : supprimer ce fichier, le verrouillage est alors sans code.
  • Limite honnête : cela ne verrouille que la fenêtre Oratio (protection contre les regards, chat sur le clavier, enfants). Qui est assis devant le Pi peut utiliser derrière le bureau ou le terminal. Le vrai verrouillage de tout le système est fait par la tuile « Verrouiller » du centre de contrôle (swaylock, mot de passe de connexion).

38.7 Profils de concentration

  • Où : roue dentée → Réglages → « Concentration ». Interrupteur à droite = marche/arrêt ; toucher le nom = modifier le profil. Rapide : loupe → « fokus schlafen » → Entrée.
  • Un profil modifie plusieurs choses : bannières (Toutes / Seulement importantes / Aucune), mode nuit (Inchangé / Activé / Désactivé), luminosité (Inchangée / 20 / 50 / 80 %, nécessite brightnessctl). À la désactivation, tout revient comme c'était avant le premier profil.
  • Intégrés : Travail, Bricolage, Sommeil.
  • Horaire : Aucun / Tous les jours / Lun–Ven / Sam–Dim avec De/À (aussi par-dessus minuit, par ex. 22:00–07:00). Si l'on désactive soi-même le profil dans la plage horaire, il reste désactivé jusqu'à la fin de la plage.
  • Règle : les notifications arrivent toujours dans la cloche, seule la bannière se retient.
  • Fichier : Oratio_Menu/fokus.py ; Json/oratio_fokus.json.

38.8 Sélecteur d’applis

  • Où : (1) placer le widget « Sélecteur d'applications » sur une page, toucher l'ouvre (la voie pour le tactile). (2) Loupe → « App-Wechsler ». (3) Ctrl+Tab dans le menu.
  • Quoi : toutes les applications ouvertes sous forme de grandes cartes (symbole, nom, titre). Toucher une carte = la mettre au premier plan. Petit x = fermer : il devient d'abord rouge (« Sûr ? »), seul le second toucher ferme. Les flèches, Entrée, Suppr, Échap fonctionnent aussi.
  • Limite : le menu ne voit les fenêtres étrangères (Firefox, terminal) que si wlrctl tourne sous labwc. Il n'y a pas d'aperçus : sous Wayland, on ne peut pas photographier des fenêtres étrangères sans programme supplémentaire. Alt+Tab reste au système (labwc).
  • Fichiers : wechsler.py, Widget/wechsler.py.

38.9 Fond animé, sons et mode économie

  • Arrière-plan animé (roue dentée → Réglages → Apparence) : Aurora, Dégradé, Étoiles, Vagues ; fluidité Économe (6 images/s), Normale (12), Fluide (20). Par défaut : désactivé. Coût : chaque image redessine toute la vue ; perceptible sur le Pi 5 en 4K. En cas de saccades, « Économe » ou désactivé. L'effet se met en pause quand le menu n'est pas la fenêtre active. Fichier livebg.py.
  • Sons (roue dentée → Réglages → Notifications & contrôle → « Sons ») : volume Désactivé / Faible / Normal / Fort (par défaut désactivé) ; interrupteurs pour ouverture de fenêtre, nouvelle notification, écran de verrouillage. Les petits fichiers WAV sont construits par le menu lui-même la première fois dans Oratio_Menu/Sounds/. Lecture via QSoundEffect, sinon pw-play / paplay / aplay ; le son sort par la sortie actuelle. Fichier klang.py.
  • Mode économie (roue dentée → Général → Comportement → « Mode économie (tous les effets désactivés) ») : désactive l'effet pinceau, la loupe du dock, la loupe des applications ouvertes et l'arrière-plan animé. À la désactivation, les valeurs précédentes reviennent (mémorisées dans Json/oratio_sparmodus.json). Verre/Mat, changement de page et widgets ne sont pas concernés.

38.10 Télécommande par téléphone, échange avec le téléphone et point d’accès

Ce sont trois niveaux qui s'appuient les uns sur les autres. Ils ont en commun un petit serveur (Handy/handy_server.py) avec une page (Handy/handy_page.html), un code PIN et un port.

Échange avec le téléphone (fichiers et texte entre téléphone et Pi)

  • Sur le Pi : Réglages → Connexions → « Échange avec le téléphone » : Démarrer/Arrêter, « QR code & PIN », derniers fichiers arrivés (toucher = ouvrir), « Ouvrir le dossier », « Tout supprimer ».
  • Sur le téléphone : ouvrir la page (scanner le QR, saisir le PIN), carte « Fichiers & texte ». « Envoyer des fichiers au Pi » (barre de progression ; destination Handy/Austausch/, les noms identiques deviennent « Nom (2) »). Dessous la liste des fichiers du dossier d'échange : toucher = télécharger sur le téléphone, x (toucher deux fois) = supprimer sur le Pi. « Texte & presse-papiers » : saisir le texte → « Envoyer au Pi ». « Récupérer du Pi » ne fonctionne que si « Partager le presse-papiers avec le téléphone » est activé sur le Pi.
  • Important après chaque remplacement des fichiers : redémarrer une fois le serveur du téléphone, sinon l'ancien code tourne encore.
  • Confidentialité : « Partager le presse-papiers » est désactivé par défaut ; s'il est activé, chaque téléphone connecté peut lire ce qui est copié sur le Pi (mots de passe compris). Tout reste dans le réseau privé : uniquement des adresses privées, PIN, après 5 essais ratés blocage de 60 s. Le dossier d'échange n'est pas chiffré.
  • Limites : max. 4 Go par fichier, le Pi a besoin de 300 Mo de réserve ; la page tourne sans HTTPS, c'est pourquoi la copie automatique dans le presse-papiers du téléphone ne fonctionne pas dans tous les navigateurs (alors appui long sur le texte → Copier).
  • Fichiers : austausch.py ; Json/oratio_austausch.json, Json/oratio_austausch_clip.json.

Point d'accès Wi-Fi avec QR code

  • Où : Réglages → Connexions → « Point d'accès ». En haut l'interrupteur « Activer le point d'accès ». Nom par défaut « Oratio-Pi », mot de passe aléatoire à la première ouverture. 2,4 GHz (fonctionne partout) ou 5 GHz (plus rapide). « Nouveau mot de passe » en tire un nouveau.
  • QR code : tenir la caméra du téléphone dessus, le téléphone se connecte sans saisie. « Partager le Wi-Fi actuel » affiche à la place le Wi-Fi dans lequel se trouve le Pi sous forme de QR code (pour des invités ; seulement avec un mot de passe normal).
  • Technique : nécessite NetworkManager (nmcli, standard sur Raspberry Pi OS Bookworm). Le mot de passe figure en clair dans Json/oratio_hotspot.json (lecture réservée à l'utilisateur), parce que le QR code en a besoin.
  • Limite honnête : la puce Wi-Fi ne peut pas être en même temps dans le Wi-Fi de la maison et créer un point d'accès. Avec un câble LAN, Internet est conservé ; sans câble, le Pi et le téléphone n'ont pas d'Internet dans le point d'accès. La page du téléphone est en général accessible dans le point d'accès à http://10.42.0.1:8765/.
  • Fichier : hotspot.py.

38.11 Caméra et capture d’écran

  • Où : roue dentée → Réglages → Système → « Caméra & capture d'écran ». Dans la loupe : « Screenshot jetzt ».
  • Capture d'écran : programme grim (fourni avec labwc). « Écran entier », « Tracer une zone » (nécessite slurp : sudo apt install slurp), ou avec délai de 3 / 5 / 10 s. La fenêtre du menu se ferme d'elle-même avant. Enregistré dans le dossier Images sous screenshot_date_heure.png.
  • Caméra : caméra Raspberry Pi sur le connecteur CSI (programmes rpicam-still, rpicam-vid ; anciens systèmes libcamera-*). Aperçu (640×480, 15 images/s seulement pour s'aligner), « Photo » en pleine résolution, « Vidéo 10/30/60 s ».
  • Règles : la caméra n'appartient jamais qu'à une seule prise de vue. Si l'on ferme la fenêtre, l'aperçu s'éteint immédiatement – la caméra ne tourne jamais en cachette en arrière-plan.
  • Limites : seulement des caméras CSI, pas de webcams USB ; pas de capture d'une seule fenêtre.
  • Fichier : aufnahme.py.

38.12 Statistiques d’utilisation

  • Où : roue dentée → Réglages → Système → « Statistiques d'utilisation ». En haut Aujourd'hui / 7 jours / 30 jours.
  • Comptage : toutes les 5 s, le menu regarde ce qui est au premier plan (carte d'application ou fenêtre étrangère, cette dernière nécessite wlrctl). Plusieurs fenêtres d'une application comptent comme une seule.
  • Confidentialité : seuls sont enregistrés les noms d'applications et les secondes par jour (pas de titres, saisies, adresses) ; suppression après 90 jours. Interrupteur « Enregistrer l'utilisation » (pause) et « Tout supprimer ».
  • Limite : pour les programmes étrangers, le Pi ne peut pas reconnaître si l'on est devant l'appareil.
  • Fichier : nutzung.py ; Json/oratio_nutzung.json.

38.13 Profils de réglages

  • Où : roue dentée → Réglages → Système → « Profils de réglages ».
  • Enregistrer : saisir un nom, choisir avec des interrupteurs ce qui en fait partie : Apparence & menu, Applications/pages/widgets, Profils de concentration, Tower (motifs LED, courbe du ventilateur, pages OLED), Écran de verrouillage (désactivé par défaut).
  • Charger : toucher un profil, choisir ce qui est chargé, « Charger » → confirmation → les réglages sont remplacés et le menu redémarre. Avant chaque chargement, le menu sauvegarde l'état actuel (les 3 derniers sont conservés) : en bas « Récupérer l'état d'avant le dernier chargement ».
  • Emplacement : Json/Profile/<nom>/ (copies plus profil.json). Les profils peuvent être copiés sur un autre Pi via l'échange avec le téléphone ou USB. Les fichiers endommagés ne sont ni enregistrés ni restaurés.
  • Limites : les images d'arrière-plan et les fichiers d'icônes ne sont pas dans le profil, seulement le chemin. Non inclus : historique, utilisation, notifications, PIN du téléphone, mot de passe du point d'accès.
  • Fichier : einstellprofile.py.

38.14 Oratio OS : construire sa propre image (première ébauche)

  • Dossier : Oratio_OS/ à côté de app_ui.py. Contient bauen.sh, LIESMICH.txt et stage-oratio/ (l'étape Oratio pour pi-gen, l'outil avec lequel Raspberry Pi OS est aussi construit).
  • Construire : cd ~/Oratio_Control_Center/Oratio_OS, puis ORATIO_PASS=meinpasswort bash bauen.sh (pas avec sudo ; 40–90 minutes ; 15 Go libres). Résultat : ~/oratio-os-bau/pi-gen/deploy/*.img.xz. Écrire sur SSD ou SD avec le Raspberry Pi Imager (« Utiliser une image personnalisée »).
  • Vidéo d'intro au démarrage : le Pi lit une vidéo en plein écran (mpv, sans bureau, service oratio-intro.service) puis lance le Control Center. Interrupteur : roue dentée → Général → « Vidéo d'intro au démarrage » (seulement dans Oratio OS). Derrière se trouve le fichier /var/lib/oratio/intro.aus.
  • État : pas construit sur du vrai matériel ; image de démarrage, assistant de configuration, Ollama/Gemma et un programme de mise à jour manquent encore. En cas d'erreurs : regarder la fin de la sortie du terminal ou journalctl -u oratio-intro.
