45.1 À quoi il sert

Le vérificateur de hash de fichiers et de doublons calcule pour de nombreux fichiers une empreinte (SHA-256) et trie ensuite : les fichiers de même empreinte sont identiques par leur contenu, même s'ils portent des noms différents. On trouve ainsi les fichiers en double et on sait combien de place on peut gagner. C'était l'un des premiers scripts du projet A (chapitre 32) et il existe comme programme sous plusieurs formes :

Forme Fichier Lignes
Script Bash pour terminal (Raspberry Pi et Linux) hashchecker.sh ca. 1300
Script PowerShell pour Windows hashcheckerpower.ps1 ca. 1370
Fenêtre de verre dans le Control Center (Python) Apps/HashChecker/hash_checker.py ca. 980
Fenêtre de verre dans le Control Center (plugin C++) Apps/HashChecker/hash_checker.cpp ca. 1700

C'est un bon exemple de ce à quoi ressemble la même idée en trois langages – idéal pour comparer.

45.2 L’idée en quatre étapes

  1. Rassembler tous les fichiers (coller les chemins ou les choisir par une fenêtre de sélection).
  2. Calculer la valeur SHA-256 de chaque fichier.
  3. Regrouper les fichiers de même valeur dans un groupe.
  4. Les groupes de plus d'un fichier sont des doublons ; la somme des tailles « en trop » est la place que l'on peut récupérer.

Pourquoi SHA-256 et pas seulement la taille ? Deux fichiers peuvent avoir la même taille mais être différents. Un hash cryptographique change complètement dès un seul bit modifié. Deux fichiers différents avec le même SHA-256 sont pratiquement exclus.

45.3 Le cœur dans le script Bash

Le script contient la boucle principale sur tous les fichiers. Le cœur, légèrement abrégé :

declare -A hash_known hash_paths hash_counts hash_sizes   # assoziative Felder (Wörterbücher)
hash_order=()                                              # Reihenfolge, in der Hashes zuerst vorkamen

for file in "${files[@]}"; do
    file_size="$(stat -c '%s' -- "$file" 2>/dev/null || printf '0')"
    hash="$(sha256sum -- "$file" 2>/dev/null | awk '{print $1}')"

    if [[ -z "${hash_known[$hash]+vorhanden}" ]]; then     # Hash zum ersten Mal gesehen
        hash_known["$hash"]=1
        hash_order+=("$hash")
        hash_paths["$hash"]="$file"
        hash_counts["$hash"]=1
        hash_sizes["$hash"]="$file_size"
    else                                                   # schon bekannt: Duplikat
        hash_paths["$hash"]+=$'\n'"$file"
        hash_counts["$hash"]=$((hash_counts["$hash"] + 1))
    fi
done
Ligne Explication
declare -A crée un tableau associatif (clé → valeur), ici hash → chemins
stat -c '%s' taille du fichier en octets
sha256sum -- "$file" calcule le hash ; -- protège contre les noms de fichiers commençant par -
awk '{print $1}' ne prend que la première colonne (le hash, sans le nom de fichier)
${hash_known[$hash]+vorhanden} renvoie « présent » si la clé existe, sinon vide ; c'est ainsi qu'on vérifie l'existence
$'\n' un saut de ligne comme séparateur, pour que plusieurs chemins tiennent dans une valeur de champ

Vient ensuite l'évaluation :

for hash in "${hash_order[@]}"; do
    count="${hash_counts[$hash]}"
    size="${hash_sizes[$hash]}"
    if (( count > 1 )); then
        duplicate_group_count=$((duplicate_group_count + 1))
        reclaimable_bytes=$((reclaimable_bytes + (count - 1) * size))
    fi
done

(count - 1) * size est la place qui serait libérée s'il ne restait qu'un seul fichier par groupe.

45.4 Ce que le script sait faire en plus

  • Saisie : chemins un par un, collés en bloc (après 0,35 s sans autre caractère, le bloc collé est considéré comme terminé) ou par une fenêtre graphique de sélection.
  • Progression : un tableau de bord avec fichier X sur Y, octets traités et temps restant.
  • Sortie : sections « Fichiers identiques » (rouge), « Fichiers sans doublon » (vert), « Résumé » (groupes, fichiers en trop, place gagnée) ; sur demande sous forme de rapport texte et de CSV.
  • Tolérance aux erreurs : set -u (variable non définie = erreur), mais pas set -e : un fichier illisible n'interrompt pas l'exécution, il atterrit dans une liste d'erreurs.
  • Conditions : bash, sha256sum, find, stat, sort, date – le script les vérifie au démarrage.

45.6 À essayer soi-même

bash hashchecker.sh

ou seulement le cœur dans le terminal :

find ~/Bilder -type f -exec sha256sum {} + | sort | uniq -w64 -d --all-repeated=separate

La ligne calcule le hash de tous les fichiers de ~/Bilder, trie et n'affiche que les lignes dont les 64 premiers caractères (le hash) apparaissent plusieurs fois. C'est la version courte du programme entier.
