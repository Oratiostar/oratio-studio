Es gibt vier Gerätearten. Das Wichtigste ist zu verstehen, was jedes kann und was nicht. Das kostet Anfänger oft Zeit, zum Beispiel wenn Raspberry-Pi-Code auf dem ESP32 nicht läuft.

15.1 Der große Unterschied

Ein Raspberry Pi ist ein kompletter Computer mit Linux. Ein Mikrocontroller (Arduino, ESP32, Pico) ist ein kleiner Chip, auf dem genau ein Programm läuft, ohne Betriebssystem.

Raspberry Pi 4 / 5 ESP32 / ESP32-S3 Arduino Nano Raspberry Pi Pico H
Art Mini-Computer mit Linux Mikrocontroller Mikrocontroller Mikrocontroller (Chip RP2040)
WLAN / Bluetooth ja ja nein nein
Startzeit 15–30 Sekunden (Boot) 1–2 Sekunden sofort sofort
Stromverbrauch hoch niedrig sehr niedrig sehr niedrig
Programmiert mit Python, C++, Shell Arduino/C++ Arduino/C++ C++ (Pico-SDK), MicroPython
Internet, Wetter, Webseiten direkt möglich über WLAN mit eigenem Code nur mit Zusatzhardware nur mit Zusatzhardware

Das „H" beim Pico H bedeutet nur, dass die Stiftleisten schon angelötet sind. Er hat kein WLAN.

15.2 Was auf dem ESP32 *nicht* läuft

Mein Code für die LED-Matrix am Raspberry Pi benutzte Dinge, die es auf dem ESP32 nicht gibt:

#include "../include/led-matrix.h"   // eine Raspberry-Pi-Bibliothek
system("hostname -I");               // Linux-Befehle
popen(...)

Auf dem Mikrocontroller gibt es kein Linux, deshalb muss man die Teile umschreiben: Uhrzeit per WLAN holen (NTP), Wetter direkt über die Web-API laden, eine ESP32-taugliche HUB75-Bibliothek verwenden. Die Animationen (Mario, Radar, Feuerwerk) lassen sich übernehmen, aber der Code ist neu zu schreiben.

Faustregel: Braucht ein Programm Internet, Dateien und Linux-Befehle, passt der Pi. Soll es schnell starten, wenig Strom brauchen und einfach nur etwas anzeigen, passt ein Mikrocontroller.

15.3 Eigene KI?

  • Auf dem ESP32 geht nur sehr wenig: Wake-Word wie „Hallo Oratio", einfache Sprachkommandos, Sensoren. Ein großer Chatbot läuft dort nicht.
  • Auf dem Pi 4 oder Pi 5 geht ein kleiner lokaler Sprachassistent (Kapitel 24).
  • Der ESP32 kann ein Helfer sein: Sensoren, Relais, Knöpfe und Licht schalten, während die KI auf dem Pi läuft.
