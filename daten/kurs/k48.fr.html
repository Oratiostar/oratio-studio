48.2 Droits et propriétaires

Symptôme : Permission denied à l'écriture, à la suppression, au démarrage ; le fichier n'est pas enregistré ; le programme ne peut pas écrire ses réglages.

ls -l datei            # Besitzer und Rechte
id                     # wer bin ich, in welchen Gruppen
stat datei             # genaue Rechte in Zahlen
Sortie Interprétation Solution
-rw-r--r-- root root Le fichier appartient à root ; l'utilisateur normal n'a pas le droit d'écrire sudo chown oratio:oratio datei
drwxr-xr-x sans w pour l'utilisateur rien ne peut être créé dans le dossier sudo chmod u+w ordner ou changer le propriétaire
Disque « en lecture seule » Propriétaire root, ou système de fichiers monté en lecture seule sudo chown -R oratio:oratio /media/oratio/NAME ; mount | grep NAME montre ro
Accès à /dev/ttyUSB0 refusé L'utilisateur n'est pas dans le groupe dialout sudo usermod -aG dialout $USER, se reconnecter
Accès à I²C/GPIO refusé Groupes i2c, gpio sudo usermod -aG i2c,gpio $USER, se reconnecter

Règle empirique : quand un programme crée lui-même des fichiers, il ne doit pas être lancé avec sudo, sinon ces fichiers appartiendront ensuite à root.

48.4 Espace et disques

Symptôme Commande Interprétation Solution
« No space left on device » df -h, df -i place ou inodes pleins trouver les gros dossiers : sudo du -xh / --max-depth=2 | sort -h | tail -20 ; ncdu /
Système lent, disque plein df -h / Le système de fichiers racine est plein sudo apt clean, journalctl --vacuum-size=200M, supprimer les anciennes sauvegardes
Disque invisible lsblk, lsusb, dmesg | tail il n'apparaît nulle part : câble/alimentation ; dans dmesg pourtant oui : non monté sudo mount /dev/sda1 /mnt
Disque « busy » au démontage lsof +f -- /media/oratio/NAME un programme l'utilise fermer le programme ; ne pas ouvrir le gestionnaire de fichiers là
La partition n'affiche pas p1/p2 après dd lsblk Linux n'a pas relu la table sudo partprobe /dev/mmcblk0
Partition trop petite après un clone lsblk, sudo parted /dev/X print La copie a la taille de la source agrandir la partition (chapitre 7, 28.12)
Système de fichiers « dirty » ou endommagé sudo fsck /dev/sda1 (démonté !) ne réparer que lorsque le disque est démonté
Le nouveau disque ne démarre pas blkid, cat /proc/cmdline, cat /etc/fstab PARTUUID ne correspond pas adapter cmdline.txt et fstab (chapitre 8.4)

Règle : avant mkfs, fdisk, parted, dd, rm -r, toujours lsblk, et reconnaître le disque à sa taille.

48.5 Processus et services

Symptôme Commande Interprétation Solution
Le programme tourne en double ps aux | grep name l'ancien processus est encore actif pkill name, redémarrer
Port occupé ss -tulpn | grep PORT un autre programme écoute là l'arrêter ou choisir un autre port
Le service ne démarre pas systemctl status dienst, journalctl -u dienst -e Message d'erreur à la fin corriger la configuration ; sudo systemctl daemon-reload après modification du fichier de service
Le service ne démarre pas après redémarrage systemctl is-enabled dienst disabled sudo systemctl enable dienst
La tâche planifiée ne tourne pas crontab -l, grep CRON /var/log/syslog ou journalctl -u cron Les chemins dans cron sont courts, l'environnement est vide chemins absolus, définir PATH dans le script
Le programme ne tourne que dans le terminal, pas par l'icône cat ~/.local/share/applications/name.desktop Exec= sans chemin absolu ou Path= manquant Exec= avec le chemin complet, définir Path=, chmod +x

48.7 Pièges des éditeurs de texte

  • nano : enregistrer Ctrl+O, Entrée, quitter Ctrl+X. Pas enregistré = modification perdue.
  • Tabulations dans le code source Python : TabError ; convertir avec expand -t 4 datei > neu.
  • Éditeur Windows : produit du CRLF ; voir 48.1.
  • Le fichier ne peut pas être enregistré : vérifier le propriétaire (48.2).
