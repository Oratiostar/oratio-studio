Braucht man eine spezielle Software, um Python zu lernen? Nein, ein einfacher Editor wie Geany reicht. Hier die Grundlagen, an Beispielen aus einem echten Projekt: Dateien öffnen, Funktionen suchen, Fehler finden, Variablen ändern, Comboboxen einbauen, Layouts verändern und Programme starten.

22.1 Das erste Programm

  1. Geany öffnen, neue Datei anlegen.
  2. Schreiben: print("Hallo Oratio")
  3. Als hello.py speichern. Die Endung .py ist wichtig, sie sagt Geany, dass es Python ist.
  4. Ausführen: in Geany über das Menü Erstellen → Ausführen, oder auf das kleine Raketen- oder Papierflieger-Symbol klicken. Im Terminal geht es mit python3 hello.py.

Variablen

elif ist „sonst wenn". pass heißt „nichts tun". Beim Erweitern auf eine vierte Seite musste an jeder Stelle ein weiteres elif index == 3: ergänzt werden. Das ist ein häufiger Fehler: man ändert nur eine von mehreren Stellen.

    col = app["col"]

try:

22.3 Einrückung ist Teil der Sprache

In Python bestimmt die Einrückung, was zu was gehört. Das führt zu einem seltsamen Fehler: Wenn def run_oled_loop(self): weiter eingerückt ist als def oled_ui_4_show(self):, hält Python die zweite Funktion für einen Teil der ersten. Richtig:

def oled_ui_3_show(self, pi_temperature, pi_duty):
    ...

def oled_ui_4_show(self):
    ...

def run_oled_loop(self):
    ...

Die beiden def müssen exakt untereinander stehen. In Geany in die Zeile klicken und prüfen, ob das d von def bei beiden in derselben Spalte steht.

22.4 JSON – Einstellungen in einer Datei

Mein Control Center speichert Apps und Einstellungen in JSON-Dateien. JSON ist ein Textformat für strukturierte Daten:

{
    "id": "cpu_temp",
    "name": "CPU Temp",
    "tool": "cpu_temp",
    "slot": 5,
    "category": "system",
    "color": "#404040",
    "icon": "Pi_Tools/Icons/cpu_temp.png"
}

Lesen und Schreiben in Python:

import json

with open("oratio_apps.json", "r") as f:
    apps = json.load(f)

for app in apps:
    app["slot"] = app["row"] * 6 + app["col"]

with open("oratio_apps_slot.json", "w") as f:
    json.dump(apps, f, indent=4)

Regeln: In JSON stehen Texte in doppelten Anführungszeichen, zwischen Einträgen steht ein Komma, aber nach dem letzten Eintrag keins. Ein einziges falsches Komma lässt das Programm nicht mehr starten. Das ist mir mehrfach passiert („Meine App startet nicht mehr").

22.5 Typische Fehlermeldungen in Python

Meldung Bedeutung Beispiel
NameError: name 'screen4_config' is not defined eine Variable wurde nie angelegt screen3_config = ...get('screen4') stand doppelt, screen4_config fehlte
UnboundLocalError: cannot access local variable 'page' Variable wird benutzt, bevor sie einen Wert hat Zeilen mit page = ... auskommentiert, aber if page != ... blieb stehen
IndentationError falsche Einrückung Funktion zu weit eingerückt
SyntaxError ungültiger Code zwei except Exception as e: hintereinander

Wie solche Fehler zu finden sind: Die Fehlermeldung nennt Datei und Zeilennummer. Mit sed -n '430,445p' datei.py erscheint genau diese Stelle. Mit grep -n "page" datei.py zeigen sich alle Verwendungen.

22.6 Debuggen mit print

Wenn ein Knopf „nichts tut", wird Schritt für Schritt geprüft:

  1. Ist der Knopf mit der Funktion verbunden? (self.btn5.clicked.connect(self.open_kanshi_dialog))
  2. Gibt es die Funktion überhaupt? (grep -n "def open_kanshi_dialog" datei.py)
  3. Wird sie aufgerufen? Als erste Zeile in die Funktion schreiben: print("Kanshi geklickt") und starte das Programm im Terminal mit python3 app_ui.py. Erscheint der Text, ist die Verbindung in Ordnung, und der Fehler liegt innerhalb der Funktion.
