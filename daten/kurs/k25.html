Der wichtigste Unterschied: Bei Bash ist alles Text. Bei PowerShell sind es Objekte. In PowerShell liefert Get-Process zum Beispiel Objekte mit Eigenschaften wie Name, CPU, Id, die man mit Where-Object oder Select-Object direkt ansprechen kann. In Bash müssen die Textzeilen mit grep, awk oder cut zerlegt werden.

25.6 Typische Stolpersteine beim Wechsel

  1. Pfadtrenner. C:\Users\Oratio\Desktop unter Windows, /home/oratio/Desktop unter Linux.
  2. Zeilenenden. Windows speichert Textdateien mit Wagenrücklauf und Zeilenvorschub (CRLF), Linux nur mit Zeilenvorschub (LF). Ein .sh-Script mit Windows-Zeilenenden bricht oft mit einer Meldung wie bad interpreter: /bin/bash^M ab. Reparatur: sed -i 's/\r$//' script.sh.
  3. Ausführbar machen. Unter Linux braucht ein Script chmod +x script.sh und wird mit ./script.sh gestartet. Unter Windows reicht der Doppelklick auf .bat und .ps1 je nach Einstellung.
  4. PowerShell-Skripte sind standardmäßig gesperrt. Falls .ps1 nicht startet, gibt es eine Meldung über die Ausführungsrichtlinie. Einmalig und nur für die aktuelle Sitzung kann man sie lockern: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass.
  5. Groß-/Kleinschreibung. Datei.TXT und datei.txt sind unter Linux zwei verschiedene Dateien.
  6. Leerzeichen im Pfad. Immer in Anführungszeichen setzen: cd "/media/oratio/SHARE/meine roms".

25.7 Ein Beispiel: das Hash-Skript

Ein praktisches Beispiel ist ein Skript, das Dateien per Drag and Drop entgegennimmt, für jede Datei einen SHA-256-Hash berechnet und Dateien mit gleichem Hash als Duplikate gruppiert. Der Kern in PowerShell:

$files  = Get-ChildItem -Recurse -File -Path $ordner
$groups = $files | ForEach-Object { Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256 } |
          Group-Object Hash
foreach ($g in $groups) {
    if ($g.Count -gt 1) {
        Write-Host "Duplikate:" $g.Group.Path
    }
}

Der gleiche Gedanke in Bash:

find "$ordner" -type f -exec sha256sum {} + | sort | uniq -w64 -D

Verbesserungen:

  • Ordner rekursiv durchsuchen, damit nicht nur einzelne Dateien funktionieren.
  • Ungültige Pfade mit einer Warnung überspringen statt abzubrechen.
  • Zuerst nach Dateigröße gruppieren und nur Dateien mit gleicher Größe hashen. Das spart oft 90 bis 99 Prozent der Hash-Berechnungen, weil unterschiedlich große Dateien nie identisch sein können.
  • Fortschrittsanzeige, Laufzeit, Restzeit und Export als TXT und CSV auf den Desktop.

Typischer Fehler beim Umsetzen: Das Skript bricht nach „41 Dateien gefunden" mit Cannot bind argument to parameter 'Text' because it is an empty string ab. Ursache: Ein Cmdlet (zum Beispiel Write-Host oder Write-Progress) bekommt einen leeren Text als Pflichtparameter, weil eine Variable noch leer ist. Lösung: Variable vorher prüfen oder mit einem Standardwert belegen. Mehr dazu im Fehlerlexikon (Kapitel 53 ff.).

Merke: Beim Umsetzen eines Scripts von Bash nach PowerShell ändert sich nicht die Idee, sondern die Syntax: Variablen mit $, Objekte statt Text, andere Namen für die Befehle.
