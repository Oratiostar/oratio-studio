Ce chapitre résume ce qui est dispersé dans les parties précédentes et rassemble les questions restées ouvertes.

14.1 Alimentation et stabilité

Signes Vérifier Mesure
Symbole d'éclair, saccades, redémarrages vcgencmd get_throttled Alimentation officielle, câble court et de bonne qualité
Le Pi 5 affiche « USB boot requires high current » Message au démarrage Alimentation 5 V / 5 A
SSD non détecté sur le Pi lsblk, dmesg Câble, alimentation, réglages PCIe

14.2 Écrire des images

Ordre éprouvé :

  1. Se procurer un programme d'écriture : sur le Pi sudo apt install rpi-imager, sur le PC Raspberry Pi Imager ou Etcher.
  2. Choisir l'image adaptée (tenir compte de l'appareil, chapitre 26.2).
  3. Choisir le support et vérifier précisément qu'il s'agit du bon lecteur.
  4. Écrire, puis ouvrir la partition de démarrage et la contrôler.

Avec dd dans le terminal : une cible mal choisie (of=) écrase le mauvais lecteur. Regardez donc d'abord lsblk.

14.3 Plusieurs systèmes

Variante Avantage Inconvénient
Un système par support (SD, NVMe, USB), choix avec la barre d'espace au démarrage simple, bien séparé clavier nécessaire sur le Pi
Ordre fixe via raspi-config aucune saisie nécessaire on n'accède à l'autre système qu'à la main
Plusieurs systèmes sur un SSD (plusieurs partitions) un seul lecteur plus de travail, Possibles par exemple : Raspberry Pi OS, Batocera, LibreELEC, RetroPie, DietPi, Ubuntu

14.4 SSH depuis l’iPhone

Par SSH (par exemple depuis le téléphone), on travaille confortablement dans le terminal. C'est pratique pour le terminal, mais cela n'aide pas pour le menu de démarrage du bootloader : là, un clavier doit être branché directement sur le Pi.

14.5 Mises à jour et entretien

Un Raspberry Pi comporte trois éléments distincts qui se mettent à jour : le système d'exploitation, le firmware du bootloader (dans l'EEPROM) et des programmes comme l'Imager sur le PC.

sudo apt update                    # Paketliste holen
sudo apt full-upgrade -y           # System und Kernel aktualisieren
sudo apt autoremove --dry-run      # erst ansehen, was entfernt würde
sudo rpi-eeprom-update             # zeigt, ob neuere Bootloader-Firmware bereitsteht
sudo rpi-eeprom-update -a          # einspielen (danach Neustart)
Message / question Signification
« Une nouvelle mise à jour est disponible » dans Raspberry Pi Imager concerne l'Imager sur le PC, pas le système sur le Pi. Mettre à jour l'Imager via sa fonction de mise à jour ou le site officiel
Après une mise à jour du noyau, quelque chose se comporte autrement redémarrage nécessaire ; un noyau en cours d'exécution n'est pas remplacé
Après la mise à jour, un réglage a disparu vérifier config.txt/cmdline.txt (chapitre 8)

Avant les grosses mises à jour, faire une sauvegarde (chapitre 9). Si vous utilisez le Control Center, sauvegardez aussi le dossier Json/ (il contient tous les réglages).

14.6 Ordre et restauration

  • Un dossier par projet (par exemple ~/Oratio_Control_Center, ~/arduino_projekte/oled_uhr). Cela évite les recherches et les confusions.
  • Avant chaque modification importante, une copie du dossier ou un fichier d'archive : tar -czf ~/Sicherung_$(date +%F).tar.gz -C ~ Projektordner.
  • Tester la restauration, pas seulement sauvegarder : extraire l'archive dans un autre dossier et vérifier que le programme démarre.
  • Git conserve chaque version et permet de revenir en arrière (chapitre 3.3).
