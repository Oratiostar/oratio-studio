3.1 apt – paquets pour Raspberry Pi OS

apt est le gestionnaire de paquets. Il récupère des programmes sur Internet et les installe.

sudo apt update          # Paketliste aktualisieren (nur die Liste!)
sudo apt upgrade -y      # installierte Programme aktualisieren
sudo apt full-upgrade -y # auch Pakete, die neue Abhängigkeiten brauchen
sudo apt install htop    # Programm installieren
apt search vlc           # nach einem Programm suchen
sudo apt remove vlc      # Programm entfernen
sudo apt autoremove      # nicht mehr gebrauchte Abhängigkeiten entfernen
sudo apt clean           # heruntergeladene Paketdateien löschen

Nettoyer en sécurité : autoremove ne supprime normalement pas les programmes installés volontairement. Il retire seulement les dépendances dont plus personne n’a besoin. La règle de prudence s’applique quand même : d’abord regarder seulement (apt autoremove --dry-run).

sudo apt autoremove --dry-run

Cela montre seulement ce qui serait retiré et ne supprime rien.

Routine de mise à jour : avec sudo apt update && sudo apt upgrade -y, le Pi reste à jour. update récupère la liste, upgrade installe les nouveautés.

3.2 pip et venv – paquets Python

Les bibliothèques Python s’installent avec pip. Sur le Pi (Debian), il faut souvent pour cela un environnement virtuel, afin de ne pas déranger le système.

python3 -m venv ~/.venvs/mein_projekt
source ~/.venvs/mein_projekt/bin/activate
pip install piper-tts
deactivate

source ... activate active l’environnement. Sans venv, pip exige souvent sur les systèmes récents l’option --break-system-packages. Il faut la connaître et ne l’utiliser que consciemment.

3.3 git – télécharger du code

git clone https://github.com/hzeller/rpi-rgb-led-matrix.git
cd rpi-rgb-led-matrix

git clone copie tout un projet de GitHub sur le Pi. C’est ainsi que j’ai installé la bibliothèque de la matrice LED.

3.4 curl et wget – fichiers depuis le réseau

curl -fsSL https://ollama.com/install.sh | sh
curl -sSLO --fail https://raw.githubusercontent.com/framps/raspiBackup/master/published/raspiBackupInstallUI.sh
wget <URL>

Avec curl ... | sh, un script d’installation est exécuté directement. C’est pratique, mais on fait confiance à la source. À n’utiliser que depuis le site officiel du projet.

3.5 Alias et le fichier .bashrc

Un alias donne un nom court à une longue commande. Dans ~/.bashrc se trouvent les réglages personnels du shell :

nano ~/.bashrc

J’y ai créé ces alias (exemple pour la résolution) :

alias fullhd='wlr-randr --output HDMI-A-2 --mode 1920x1080'
alias fourk='wlr-randr --output HDMI-A-2 --mode 3840x2160 --scale 1'
alias fourkbig='wlr-randr --output HDMI-A-2 --mode 3840x2160 --scale 3'

Pour que la modification s’applique immédiatement :

source ~/.bashrc

Différence : enregistrer et source. Enregistrer (Ctrl+O) écrit le fichier sur le disque. source le charge dans le terminal déjà ouvert. Autre possibilité : fermer le terminal et le rouvrir.

Différence : alias et echo. alias crée un raccourci. echo affiche seulement du texte. Avec echo "texte" >> fichier.txt, le texte est ajouté à un fichier.
