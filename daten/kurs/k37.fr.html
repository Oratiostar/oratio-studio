37.1 L’interface en un coup d’œil

Le Oratio Menu est la partie qui ressemble à un écran d'accueil de téléphone. Il se compose des zones suivantes :

Zone Emplacement à l'écran Rôle
Barre de verre tout en haut Heure, fenêtres en cours, menu
Groupe de symboles en haut à droite Loupe, cloche, pinceau, WLAN, Bluetooth, microphone, centre de contrôle, roue dentée
Grille avec pages milieu de l'écran Tuiles (applications et widgets), points de page en bas
Dock en bas Applications favorites, toujours visibles
Fenêtre de contrôle s'ouvre sous le groupe de symboles interrupteurs rapides (WLAN, son, luminosité, musique …)

Presque tout le reste est une fenêtre de verre qui s'ouvre à côté de cette vue ou par-dessus et qui est dessinée par la boîte à outils glass_ui.py (chapitre 36.5).

37.2 Tuiles, pages et mode d’édition

Grille : par défaut 10 colonnes × 5 lignes par page. Une tuile a dans oratio_apps.json les valeurs slot, row, col. On en déduit la page (calcul comme au chapitre 35 : page = slot divisé par tuiles par page).

Mode édition : symbole pinceau en haut à droite → crayon. Alors :

  • Glisser une tuile = la déplacer (glisser au-delà du bord change de page, après 0,75 s d'attente, puis 1,1 s jusqu'à la page suivante)
  • Clic droit ou appui long sur une tuile = menu : Modifier, Taille, Couleur, Nom, Retirer
  • Glisser sur le dock = application dans le dock

Grandes tuiles : les widgets et certaines applications ont des tailles en cases (1×1, 2×1, 2×2, 4×2, 4×4).

Couleur : clic droit → Couleur. L'interrupteur « Couleur du système » colore la tuile dans l'aspect verre gris des widgets, qui suit le thème.

Noms : l'orthographe reste comme on la définit soi-même. Une règle automatique (« chaque mot en majuscule, omettre “Oratio” ») a existé brièvement et a été retirée, parce qu'elle abîmait des noms comme « Oratio Media Player ». Renommer : ouvrir la tuile en mode édition ou modifier le nom directement dans oratio_apps.json.

37.3 Ajouter une nouvelle appli (depuis l’interface)

Menu → « Ajouter une application » ouvre une fenêtre avec des champs pour le nom, le fichier (le script), l'icône, la couleur, le lancement en terminal et « Ouvrir dans l'aspect Oratio » (= embed). Le fichier peut être choisi directement via la médiathèque. Après « Enregistrer », le programme écrit une nouvelle entrée dans oratio_apps.json (chapitre 36.7) et la tuile apparaît à la prochaine place libre.

37.4 Widgets : un fichier par widget

Chaque widget est un fichier dans le dossier Oratio_Menu/Widget/. Un nouveau fichier ici apparaît de lui-même dans la galerie de widgets. Un fichier de widget contient :

Nom dans le fichier Signification
KIND identifiant interne (par ex. "network")
NAME Nom affiché dans la galerie
SIZES tailles autorisées sous forme de liste, par ex. [(1,1),(2,1),(2,2),(4,2)]
MIN plus petite taille utile
FAST True si le widget doit être redessiné rapidement (par ex. égaliseur)
ORDER Ordre dans la galerie
paint(c) la fonction de dessin : reçoit une zone de dessin c et peint le widget
on_click (facultatif) ce qui se passe au toucher
APP / OPEN_APP (facultatif) quelle application s'ouvre au toucher
tick, data_tick (facultatif) actualisation régulière ou récupération de données

Les données dont plusieurs widgets ont besoin (CPU, réseau, ventilateur …) sont récupérées par un fichier commun _common (WDATA), pour que chaque widget n'interroge pas lui-même.

Exemples de widgets existants : CPU, RAM, réseau, ventilateur, LED, OLED, horloge, météo, calculatrice, minuteur, réveil, égaliseur, musique, sélecteur d'applications, pile.

Comment un widget cassé est traité : au chargement, chaque fichier de widget est dans un try/except. Une erreur dans un fichier ne fait disparaître que ce widget de la galerie.

Galerie de widgets

Menu → « Widgets » (ou roue dentée → Réglages → Applications & pages → Widgets). Chaque widget est montré avec un aperçu en direct. Sous l'aperçu, toucher une taille : le widget atterrit sur la page actuelle.

Pile de widgets

Dans la galerie, en haut, basculer sur « Pile (plusieurs dans une carte) », toucher au moins deux widgets (coche), choisir la taille (2×2 / 4×2 / 4×4) et « Défilement automatique » (Désactivé / 5 / 10 / 30 s), « Créer la pile ». Ensuite, une carte montre à chaque fois un widget. Glisser ou utiliser les points sur le bord droit pour changer. Modifier : clic droit → « Modifier la pile ». Dans oratio_apps.json apparaît une entrée "widget": "stack".

Limites : la pile ne change pas selon l'heure, seulement selon le rythme. Les widgets à commande propre (touches de la calculatrice) ne peuvent qu'être regardés dans la pile ; toucher ouvre l'application correspondante.

37.5 La fenêtre de contrôle

Le centre de contrôle (symbole en haut à droite) contient des tuiles pour WLAN, Bluetooth, mode avion, son, luminosité, musique, écran, fenêtres d'applications, mode nuit, LED et d'autres. Caractéristiques :

  • 4 colonnes, au plus 7 rangées. Ce qui ne tient pas est désactivé. Dans les réglages du CC, « Défilement » active une longueur illimitée.
  • Toutes les tuiles sont librement réglables en largeur (1–4) et en hauteur (1–3) ; le contenu s'adapte.
  • Mode édition : appuyer longuement sur un endroit vide (pas sur des boutons !). Ensuite, glisser les tuiles, coin inférieur droit = taille, « Terminé » en bas à droite termine. Le pointeur devient une main au coin de poignée.
  • Autres tuiles (désactivées au départ) : redémarrer le Pi, capture d'écran, navigateur, musique, notes. Activer sous « Autres tuiles ».
  • « Éteindre », « Pi redémarrer » et « CC redémarrer » ne demandent pas de confirmation, un appui suffit. La fenêtre d'énergie des réglages du menu continue de demander.
  • La tuile musique commande YouTube & Co. (via playerctl) et l'Oratio Media Player (via de petits fichiers /tmp/oratio_medien_state.json et /tmp/oratio_medien_cmd). Toucher le titre ouvre le Media Player.
  • Après chaque démarrage du programme, « Muet » est levé une seule fois et le volume 0 est mis à 50 %.

37.6 Activer le Wi-Fi et le Bluetooth – deux leçons

  1. Le Bluetooth repasse sur « désactivé » : le verrou radio était actif. Avant d'activer, il doit être levé : rfkill unblock bluetooth. Le programme le fait maintenant lui-même.
  2. Le symbole oscille pendant que le WLAN démarre : le symbole change maintenant immédiatement et reste ainsi jusqu'à ce que la vraie interrogation confirme le nouvel état. Si cela ne réussit pas après environ 12 s, il affiche de nouveau l'état réel. Les interrogations (WLAN, Bluetooth, mode avion, son, réseau) se font en même temps au lieu de successivement, la fenêtre s'ouvre plus vite.

Leçon : une interface qui ne fait qu'interroger l'état du système paraît lente. Mieux vaut d'abord montrer l'état attendu, puis le confirmer.

37.7 Rester fluide : saccades au déplacement et au changement de page

Sur le Pi 5 en 4K sans accélération graphique, il y a eu plusieurs problèmes de saccades. Le chemin n'a pas été droit :

Essai Résultat Pourquoi
Continuer à animer tous les widgets pendant qu'une application est glissée saccade chaque pas de souris redessine tout
Mettre en pause les animations des widgets pendant le glissement, ne dessiner les marquages qu'en cas de changement, recherche de cible au plus 30× par seconde ne saccade plus moins de travail de dessin par seconde
Faire glisser le changement de page comme deux images (ancienne et nouvelle page sous forme de photo) éclair blanchâtre les images de pages se superposaient pendant 90 ms aux vraies surfaces de verre translucides – du verre empilé en double paraît blanchâtre
Les deux images dans un seul widget, déplacées par pixels entiers mieux, mais coûteux –
Le menu détecte que le glissement tourne à moins d'environ 14 images/s et bascule directement propre au lieu de saccadé en 4K sans accélération, le glissement n'est pas possible
État actuel : les vraies tuiles glissent vers l'extérieur et vers l'intérieur bien pas d'images, rien n'est précalculé au repos

À retenir : avec des surfaces translucides, ne jamais superposer deux couches, sinon un saut de luminosité apparaît. Et : si une animation ne tourne pas de façon fluide sur le matériel, mieux vaut la supprimer complètement que la laisser saccader.

Autres accélérateurs : les images d'icônes sont limitées à 512 pixels au maximum et les images mises à l'échelle sont mises en cache ; le calcul de la police est mémorisé (widgets environ 5× plus rapides). Les widgets en direct normaux tournent à environ 8 au lieu de 15 images par seconde.

37.8 Applis intégrées (sélection)

Dans le dossier Oratio_Menu/Apps/, chaque application se trouve dans son propre sous-dossier (script + icon.png) :

Application Rôle
Oratio Media Player Musique avec pochette, barres de niveau, indication de qualité (codec, kHz, bit, kbit/s) ; met en pause l'autre musique (playerctl)
Navigateur Favoris (étoile, Ctrl+D), historique, recherche dans la page (Ctrl+F), zoom (Ctrl +/−/0), vidéo en plein écran, téléchargements vers ~/Downloads ; les favoris sont dans ~/.local/share/oratio_browser
Fichiers Menu du clic droit, coller avec le même nom demande (Remplacer / Garder les deux / Annuler), aperçu d'image
Calculatrice vraie application avec taille de fenêtre petite/normale/grande/plein écran, verre/mat ; le widget l'ouvre
Minuteur, réveil, météo suivent le réglage « Fenêtre d'application → Apparence » (Verre / Mat / Système)
Tâches Liste de tâches (oratio_aufgaben.py)
Icon Werkstatt dessine des icônes d'applications
Strike petit jeu
Labor Poste de mesure (chapitre 38.5)
Backup Clone du système (chapitre 39.2)
Bauteile, Akademie, Atlas Ouvrages de référence d'électronique (chapitre 39.6)

Leçon importante sur les icônes : il y a eu un essai pour que les icônes avec leur propre fond remplissent toute la tuile (couper la marge vide). Il a été annulé ; toutes les icônes sont de nouveau dessinées comme « plaque + icône avec une petite marge ». Une icône peut aussi n'avoir aucun fond (Media Player : seulement anneau, écriture, rouge) ; alors c'est la couleur de la tuile qui détermine l'aspect.

37.9 Clavier et joystick

Le menu peut aussi se commander sans souris (fichier Ansicht/tastatur.py) : les flèches déplacent le marquage, Entrée ouvre, Échap revient en arrière, Ctrl+Tab ouvre le sélecteur d'applications. Un petit clavier Rii avec joystick convient comme télécommande sur le téléviseur. Pour le joystick, c'est comme pour les flèches.

37.10 Les principales leçons de ce chapitre

  1. Un fichier par widget, un par application : les erreurs restent locales.
  2. D'abord montrer l'état attendu, puis le faire confirmer.
  3. Les animations doivent convenir au matériel – sur un graphisme faible, mieux vaut basculer que glisser.
  4. Tout ce qui est variable dans un fichier JSON, tout l'aspect dans la boîte à outils.
