55.1 Erreurs de compilation

Le compilateur indique fichier:ligne:colonne et le type de l'erreur. Le plus souvent, la première erreur est la vraie, les suivantes sont des erreurs en cascade.

'xyz' was not declared in this scope

Le nom est inconnu à cet endroit.

Cause Solution
La fonction est appelée avant sa définition ('pageOratio' was not declared, playMelody was not declared) Définir la fonction plus haut ou ajouter un prototype : void pageOratio();
La constante ou la couleur n'existe pas dans la bibliothèque (GC9A01A_LIGHTGREY, NOTE_FS5) Créer sa propre constante avec #define ou const, par exemple #define NOTE_FS5 740, ou utiliser une couleur existante
'sin' was not declared, 'cos' was not declared Ajouter #include <cmath>
Faute de frappe ou mauvaise écriture Comparer les noms

error: expected unqualified-id before 'if'

Une instruction (if, for, x = 1;) se trouve en dehors d'une fonction. Tout ce qui est exécutable appartient à setup(), loop() ou une autre fonction. Vérifier si les accolades { } ont été correctement fermées avant.

expected ';' before ...

Un point-virgule manque, le plus souvent dans la ligne précédente.

fatal error: xyz.h: No such file or directory (par exemple Adafruit_I2CDevice.h, led-matrix.h)

Signification : le fichier d'en-tête est introuvable.

Solution :

  • Arduino/PlatformIO : bibliothèque manquante. L'inscrire dans platformio.ini sous lib_deps (adafruit/Adafruit BusIO) ou l'installer dans l'IDE Arduino. Adafruit_I2CDevice.h fait partie d'Adafruit BusIO.
  • Exemples de matrice sur le Pi : vérifier le chemin relatif (#include "../include/led-matrix.h") ou compiler depuis le bon dossier.

*** [.pio/build/esp32dev/src/main.cpp.o] Error 1

Ce n'est que la fin : le compilateur a échoué sur main.cpp. Le vrai message se trouve au-dessus.

.red ... has no member named 'red'

Dans les versions récentes de la bibliothèque de matrice, les composantes de couleur s'appellent .r, .g, .b. Remplacer .red par .r. En cas de scintillement : --led-slowdown-gpio=4.

55.3 PlatformIO

Could not initialize Project avec UnknownPackageError: Could not find the package with 'platformio/toolchain-gccarmnoneeabi @ ~1.90201.0' requirements

Signification : PlatformIO cherche un paquet de chaîne d'outils précis dans une version fixe et ne trouve aucune version adaptée au système utilisé (par exemple Linux ARM64 sur le Pi). Ce n'est pas le Pico, VS Code ou Internet qui est cassé.

Ce qu'est une chaîne d'outils : l'ensemble compilateur, assembleur et éditeur de liens qui transforme le code C++ en programme pour la puce.

Solution : vérifier la plateforme et sa version et choisir une plateforme construite pour ARM64 (pour le Pico, la plateforme Arduino-Pico d'Earle Philhower), ou compiler le projet sur un ordinateur x86. Les indications sur la plateforme se trouvent dans platformio.ini.

No module named platformio

Dans le terminal normal, PlatformIO n'est pas installé, il se trouve dans VS Code dans un environnement propre. Appel :

~/.platformio/penv/bin/platformio --version

Si le fichier manque ou si l'environnement est endommagé, on supprime seulement cet environnement (rm -rf ~/.platformio/penv), on ferme VS Code et on le redémarre. PlatformIO le reconstruit. Les projets sont conservés.

Mauvaise indication de carte

Un clone de Nano a souvent besoin de board = nanoatmega328 avec board_build.mcu/bootloader atmega328old, sinon le téléversement échoue (avrdude: stk500_getsync(): not in sync).

55.4 Carte non reconnue ou échec du téléversement

Symptôme Cause Solution
Aucun port dans la liste (/dev/ttyUSB0 manque) Câble de charge seulement, pilote manquant, carte non reconnue Utiliser un câble de données, sous Windows installer le pilote CP210x ou CH340, vérifier ls /dev/ttyUSB* /dev/ttyACM*
Permission denied: '/dev/ttyUSB0' L'utilisateur n'est pas dans le groupe dialout sudo usermod -a -G dialout $USER, puis se reconnecter

avrdude: stk500_getsync(): not in sync (Nano) Mauvais bootloader Choisir le processeur atmega328old
Le téléversement réussit, l'écran reste vide Le programme tourne, câblage faux Scanner I²C (chapitre 17.5)
