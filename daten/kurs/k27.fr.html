27.2 Double démarrage : SteamOS et Windows

Ce qui s'est passé

  1. Windows est installé sur une partition préparée et démarre, mais SteamOS n'est ensuite plus accessible.
  2. Même avec le raccourci du menu de démarrage, SteamOS ne démarrait pas. Il a fallu le réinstaller, et Windows a été perdu au passage.
  3. Entre-temps, l'appareil s'est retrouvé en mode commande GRUB (un écran avec grub>).

Cause

Lors de l'installation, Windows écrit son propre bootloader dans la partition EFI et se place en tête de l'ordre de démarrage. L'entrée de SteamOS est alors écrasée ou repoussée dans l'ordre de démarrage. S'il faut réinstaller SteamOS à chaque fois, le problème est plus profond que le bootloader : la partition SteamOS ou la table de partitions est endommagée ou écrasée.

Outils et notions

Notion Signification
Partition EFI Petite partition contenant les fichiers de démarrage de tous les systèmes
GPT Table de partitions moderne
Free space before Espace libre avant (à gauche de) la partition. Important dans l'outil de partitionnement pour ne pas réduire le mauvais côté
GRUB Bootloader utilisé par les systèmes Linux
rEFInd Gestionnaire de démarrage graphique qui détecte tous les systèmes installés et les propose au choix

Premiers secours avec grub>

exit

Cela tente de revenir au menu de démarrage. Si cela n'aide pas, il faut une réparation avec une clé de démarrage.

Supprimer rEFInd

La méthode dépend du système. Sous Linux, on supprime le dossier rEFInd de la partition EFI et l'entrée de la liste de démarrage (efibootmgr). Sous Windows, cela se fait avec bcdedit et la suppression du dossier. La méthode Mac ne s'applique pas au Steam Deck.

Windows sans clé de produit, vérifier le hash

L'installation comprend la vérification du téléchargement : comparer Get-FileHash (PowerShell) ou sha256sum (Linux) avec la valeur du site (chapitre 25.7). Une activation n'est pas immédiatement nécessaire, Windows fonctionne aussi en mode limité.

27.3 Windows 11 24H2 et le double démarrage

Observation : la mise à jour 24H2 cause souvent des problèmes en double démarrage avec SteamOS (SteamOS ne démarre plus, écran noir au changement). Il vaut donc mieux rester sur Windows 11 23H2.

Question : 23H2 passe-t-il automatiquement à 24H2 avec « Rechercher des mises à jour » ? Pas automatiquement par un clic sur les mises à jour de pilotes, mais Microsoft pousse les grandes mises à jour de fonctionnalités avec le temps. On peut l'empêcher, par exemple avec le réglage de la version cible des mises à jour de fonctionnalités dans les options de Windows Update.

À retenir : avant chaque grosse mise à jour Windows en double démarrage, faire une sauvegarde de la partition EFI et de la partition SteamOS.

27.4 SteamOS, Bazzite et Batocera

  • SteamOS est développé par Valve pour le Steam Deck.
  • Bazzite est un système de jeu basé sur Fedora, semblable à SteamOS, mais qui fonctionne aussi sur d'autres appareils.
  • Batocera est un système purement dédié aux jeux rétro (chapitre 26).

27.5 Python : Raspberry Pi contre Steam Deck

Pour apprendre Python, le Raspberry Pi est dans la plupart des cas le meilleur choix. Raisons : il est conçu pour apprendre, tourne sous Linux, il existe beaucoup de tutoriels, et l'on pourra plus tard brancher LED, capteurs et moteurs.

Important : la phrase « Python est déjà installé sur le Pi » est vraie pour Raspberry Pi OS (Python 3 y est inclus). Sur le Steam Deck (SteamOS), Python est également présent dans la base du système, mais SteamOS est un système en lecture seule. On y installe des paquets supplémentaires dans un environnement dédié (python3 -m venv, chapitre 3) ou via Flatpak.

27.6 La découverte de la « restriction » : Imager en AppImage

Il existe un piège qui n'apparaît pas sur le Steam Deck, mais bien sur le Raspberry Pi :

Un programme de flashage sous forme d'AppImage (par exemple l'Imager) fonctionne sur le Steam Deck (x86-64) directement après chmod +x. Sur le Pi 5 (ARM64), le message Exec format error apparaît, car le fichier est construit pour la mauvaise architecture de processeur.

Appareil Processeur AppImage pour amd64
Steam Deck x86-64 (amd64) fonctionne
Raspberry Pi 5 ARM64 (aarch64) Exec format error

Solution sur le Pi : installer le programme adapté depuis la source de paquets :

sudo apt update
sudo apt install rpi-imager
rpi-imager

C'est la bonne méthode, car Etcher est officiellement proposé surtout pour x86-64.
