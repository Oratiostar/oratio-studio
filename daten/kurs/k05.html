5.1 Prozesse ansehen und beenden

ps aux                        # alle laufenden Prozesse
ps aux | grep kanshi          # ist Kanshi gestartet?
top                           # live, beenden mit q
htop                          # komfortabler (sudo apt install htop)
kill 1234                     # Prozess mit der Nummer 1234 beenden
pkill kanshi                  # Prozess nach Namen beenden
pkill -f app_ui.py            # Prozess nach ganzer Befehlszeile beenden

So habe ich den Fehler bei Kanshi gefunden: ps aux | grep kanshi zeigte nur die grep-Zeile selbst. Das heißt: Kanshi läuft gar nicht, obwohl es im Autostart steht. Die Ursache war ein Syntaxfehler in der Konfigurationsdatei (siehe Kapitel 10.6).

5.2 systemd – Dienste

Auf dem Pi laufen Hintergrunddienste unter systemd.

systemctl status ssh --no-pager       # Zustand ansehen
sudo systemctl enable --now ssh       # jetzt starten und beim Boot starten
sudo systemctl restart <dienst>       # neu starten
systemctl --user status kanshi        # Dienst des eigenen Benutzers
systemctl get-default                 # grafisch (graphical.target) oder nicht

5.3 Logs lesen

journalctl -n 50       # letzte 50 Systemmeldungen
journalctl -f          # live mitlesen
dmesg | tail           # letzte Kernel-Meldungen (z. B. neue USB-Geräte)

dmesg zeigt, was der Kern erkannt hat, wenn etwas angesteckt wird, zum Beispiel einen Arduino, der als ttyUSB0 auftaucht.

5.4 Autostart beim Login (Desktop)

Dateien im Ordner ~/.config/autostart werden beim Login gestartet. Jede Datei ist ein Desktop Entry:

[Desktop Entry]
Type=Application
Name=Display Watchdog
Exec=/home/oratio/display_watchdog.sh

Bedeutung der Zeilen:

  • [Desktop Entry] – Beginn der Konfiguration
  • Type=Application – es ist ein Programm
  • Name= – Anzeigename
  • Exec= – welches Programm gestartet wird

Jede Datei in autostart beschreibt ein Programm. Die Dateien sind nicht alle gleich lang. Der Pflichtteil sind meist diese vier Zeilen.

Beachte: Das Script heißt .sh, die Autostart-Datei heißt .desktop. Diese beiden Endungen habe ich einmal verwechselt.

Bei labwc (dem Fenstermanager von Raspberry Pi OS Trixie) gibt es zusätzlich die Datei ~/.config/labwc/autostart. Dort steht zum Beispiel die Zeile kanshi &.

5.5 cron – Aufgaben nach Zeitplan

crontab -e     # Zeitplan bearbeiten
crontab -l     # Zeitplan anzeigen

Eine Zeile hat fünf Zeitfelder (Minute, Stunde, Tag, Monat, Wochentag), danach den Befehl. Beispiel „jeden Sonntag um 3 Uhr": 0 3 * * 0 /home/oratio/backup.sh. Damit läuft eine Sicherung ohne eigenes Zutun.

5.6 Neustart und Ausschalten

sudo reboot
sudo shutdown now
sudo shutdown -h now
