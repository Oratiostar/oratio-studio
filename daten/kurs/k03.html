3.1 apt – Pakete für Raspberry Pi OS

apt ist der Paketmanager. Er holt Programme aus dem Internet und installiert sie.

sudo apt update          # Paketliste aktualisieren (nur die Liste!)
sudo apt upgrade -y      # installierte Programme aktualisieren
sudo apt full-upgrade -y # auch Pakete, die neue Abhängigkeiten brauchen
sudo apt install htop    # Programm installieren
apt search vlc           # nach einem Programm suchen
sudo apt remove vlc      # Programm entfernen
sudo apt autoremove      # nicht mehr gebrauchte Abhängigkeiten entfernen
sudo apt clean           # heruntergeladene Paketdateien löschen

Sicher aufräumen: autoremove löscht normalerweise keine Programme, die bewusst installiert wurden. Es entfernt nur Abhängigkeiten, die niemand mehr braucht. Trotzdem gilt die Vorsichtsregel: erst nur ansehen (apt autoremove --dry-run).

sudo apt autoremove --dry-run

Das zeigt nur, was entfernt würde, und löscht nichts.

Update-Routine: Mit sudo apt update && sudo apt upgrade -y bleibt der Pi aktuell. update holt die Liste, upgrade installiert die Neuerungen.

3.2 pip und venv – Python-Pakete

Python-Bibliotheken kommen mit pip. Auf dem Pi (Debian) braucht man dafür oft eine virtuelle Umgebung, damit das System nicht durcheinanderkommt.

python3 -m venv ~/.venvs/mein_projekt
source ~/.venvs/mein_projekt/bin/activate
pip install piper-tts
deactivate

source ... activate schaltet die Umgebung ein. Ohne venv verlangt pip auf neuen Systemen oft die Option --break-system-packages. Die sollte man nur kennen und bewusst nutzen.

3.3 git – Code herunterladen

git clone https://github.com/hzeller/rpi-rgb-led-matrix.git
cd rpi-rgb-led-matrix

git clone kopiert ein ganzes Projekt von GitHub auf den Pi. So habe ich die LED-Matrix-Bibliothek installiert.

3.4 curl und wget – Dateien aus dem Netz

curl -fsSL https://ollama.com/install.sh | sh
curl -sSLO --fail https://raw.githubusercontent.com/framps/raspiBackup/master/published/raspiBackupInstallUI.sh
wget <URL>

Bei curl ... | sh wird ein Install-Script direkt ausgeführt. Das ist bequem, aber man vertraut der Quelle. Nur von der offiziellen Seite des Projekts verwenden.

3.5 Aliase und die .bashrc

Mit einem Alias bekommt ein langer Befehl einen kurzen Namen. In ~/.bashrc stehen die persönlichen Einstellungen für die Shell:

nano ~/.bashrc

Dort habe ich diese Aliase angelegt (Beispiel zur Auflösung):

alias fullhd='wlr-randr --output HDMI-A-2 --mode 1920x1080'
alias fourk='wlr-randr --output HDMI-A-2 --mode 3840x2160 --scale 1'
alias fourkbig='wlr-randr --output HDMI-A-2 --mode 3840x2160 --scale 3'

Damit die Änderung sofort gilt:

source ~/.bashrc

Unterschied: Speichern und source. Speichern (Strg+O) schreibt die Datei auf die Festplatte. source lädt sie in das bereits offene Terminal. Alternativ das Terminal schließen und neu öffnen.

Unterschied: alias und echo. alias erzeugt einen Kurzbefehl. echo zeigt nur Text an. Mit echo "Text" >> datei.txt wird Text an eine Datei angehängt.
