Quand le message ne figure pas dans le lexique, cette démarche aide (le chapitre 47 l'explique en détail) :

  1. Lire le message à la lettre, la dernière ligne d'abord.
  2. Ouvrir le fichier et la ligne indiqués dans le message.
  3. Qu'est-ce qui a été modifié en dernier ? Annuler la dernière modification ou la vérifier isolément.
  4. Cerner : lancer le programme dans le terminal, écrire un petit test, mettre des parties en commentaire.
  5. Vérifier l'environnement : bon dossier (pwd), bon utilisateur, bon environnement Python, bonne carte, bon port.
  6. Soupçonner le matériel en dernier : d'abord le logiciel et les réglages, puis les câbles, puis le composant.
  7. Documenter la solution : écrire le message, la cause et la commande dans son propre fichier de notes.
Message typique Première vérification
not found Nom et chemin corrects ? Installé ?
Permission denied ls -l, propriétaire, chmod, sudo
not declared Ordre, include, orthographe
IndentationError Espaces au lieu de tabulations, même profondeur
No such file Indiquer le chemin en absolu
Exec format error Architecture (uname -m)
L'écran reste noir Adresse, broches, display.display()
Le téléversement échoue Port, câble, touche BOOT, bootloader
