Anzeichen Prüfen Maßnahme

14.2 Images schreiben

Bewährte Reihenfolge:

  1. Programm zum Schreiben besorgen: Auf dem Pi sudo apt install rpi-imager, am PC der Raspberry Pi Imager oder Etcher.
  2. Passendes Image wählen (Gerät beachten, Kapitel 26.2).
  3. Medium auswählen und genau kontrollieren, dass es das richtige Laufwerk ist.
  4. Schreiben, anschließend die Boot-Partition öffnen und kontrollieren.

Beim Terminal-Weg mit dd gilt: Ein falsch gewähltes Ziel (of=) überschreibt das falsche Laufwerk. Darum vorher lsblk ansehen.

14.3 Mehrere Systeme

Variante Vorteil Nachteil
Je ein System auf eigenem Medium (SD, NVMe, USB), Auswahl über Leertaste beim Start einfach, sauber getrennt Tastatur am Pi nötig
Feste Reihenfolge über raspi-config keine Eingabe nötig man kommt nur mit Handarbeit an das andere System
Mehrere Systeme auf einer SSD (Mehrfachpartitionen) ein Laufwerk mehr Aufwand, Möglich sind zum Beispiel Raspberry Pi OS, Batocera, LibreELEC, RetroPie, DietPi, Ubuntu

14.4 SSH vom iPhone

Per SSH (zum Beispiel vom Handy) lässt sich bequem im Terminal arbeiten. Das ist praktisch für Terminal-Arbeit, aber beim Start-Menü des Bootloaders hilft es nicht: Dort muss eine Tastatur direkt am Pi hängen.

14.5 Updates und Pflege

Ein Raspberry Pi hat drei getrennte Dinge, die aktualisiert werden: das Betriebssystem, die Bootloader-Firmware (im EEPROM) und Programme wie der Imager auf dem PC.

sudo apt update                    # Paketliste holen
sudo apt full-upgrade -y           # System und Kernel aktualisieren
sudo apt autoremove --dry-run      # erst ansehen, was entfernt würde
sudo rpi-eeprom-update             # zeigt, ob neuere Bootloader-Firmware bereitsteht
sudo rpi-eeprom-update -a          # einspielen (danach Neustart)
Meldung / Frage Bedeutung
„Es gibt ein neues Update“ im Raspberry Pi Imager betrifft den Imager auf dem PC, nicht das System auf dem Pi. Imager über seine Update-Funktion oder die offizielle Seite aktualisieren
Nach einem Kernel-Update verhält sich etwas anders Neustart nötig; ein laufender Kernel wird nicht ausgetauscht
Nach dem Update fehlt eine Einstellung config.txt/cmdline.txt prüfen (Kapitel 8)

Vor größeren Updates eine Sicherung (Kapitel 9). Wer das Control Center benutzt, sichert zusätzlich den Ordner Json/ (er enthält alle Einstellungen).

14.6 Ordnung und Wiederherstellung

  • Ein Ordner pro Projekt (zum Beispiel ~/Oratio_Control_Center, ~/arduino_projekte/oled_uhr). Das erspart Suchen und Verwechslungen.
  • Vor jeder größeren Änderung eine Kopie des Ordners oder eine Archivdatei: tar -czf ~/Sicherung_$(date +%F).tar.gz -C ~ Projektordner.
  • Wiederherstellung testen, nicht nur sichern: Archiv in einen anderen Ordner entpacken und prüfen, ob das Programm startet.
  • Git hält jede Version fest und erlaubt den Weg zurück (Kapitel 3.3).
