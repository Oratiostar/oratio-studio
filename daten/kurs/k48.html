48.2 Rechte und Besitzer

Symptom: Permission denied beim Schreiben, Löschen, Starten; Datei wird nicht gespeichert; Programm kann Einstellungen nicht schreiben.

ls -l datei            # Besitzer und Rechte
id                     # wer bin ich, in welchen Gruppen
stat datei             # genaue Rechte in Zahlen
Ausgabe Deutung Lösung
-rw-r--r-- root root Datei gehört root; der normale Benutzer darf nicht schreiben sudo chown oratio:oratio datei
drwxr-xr-x ohne w für den Benutzer im Ordner nichts anlegbar sudo chmod u+w ordner oder Besitzer ändern
Laufwerk „schreibgeschützt“ Besitzer root, oder Dateisystem nur lesbar eingehängt sudo chown -R oratio:oratio /media/oratio/NAME; mount | grep NAME zeigt ro
Zugriff auf /dev/ttyUSB0 verweigert Benutzer nicht in der Gruppe dialout sudo usermod -aG dialout $USER, neu anmelden
Zugriff auf I²C/GPIO verweigert Gruppen i2c, gpio sudo usermod -aG i2c,gpio $USER, neu anmelden

Faustregel: Wenn ein Programm selbst Dateien anlegt, darf es nicht mit sudo gestartet werden, sonst gehören diese Dateien später root.

48.4 Platz und Laufwerke

Symptom Befehl Deutung Lösung
„No space left on device“ df -h, df -i Platz oder Inodes voll große Ordner finden: sudo du -xh / --max-depth=2 | sort -h | tail -20; ncdu /
System langsam, Platte voll df -h / Wurzeldateisystem voll sudo apt clean, journalctl --vacuum-size=200M, alte Backups entfernen
Platte nicht sichtbar lsblk, lsusb, dmesg | tail erscheint sie nirgends: Kabel/Strom; in dmesg aber ja: nicht eingehängt sudo mount /dev/sda1 /mnt
Platte „busy“ beim Aushängen lsof +f -- /media/oratio/NAME ein Programm benutzt sie Programm schließen; Dateimanager nicht dort öffnen
Partition zeigt nach dd nicht p1/p2 lsblk Linux las die Tabelle nicht neu sudo partprobe /dev/mmcblk0
Partition nach Klon zu klein lsblk, sudo parted /dev/X print Kopie hat die Größe der Quelle Partition vergrößern (Kapitel 7, 28.12)
Dateisystem „dirty“ oder beschädigt sudo fsck /dev/sda1 (ausgehängt!) nur bei ausgehängtem Laufwerk reparieren
Neue Platte startet nicht blkid, cat /proc/cmdline, cat /etc/fstab PARTUUID stimmt nicht überein cmdline.txt und fstab anpassen (Kapitel 8.4)

Regel: Vor mkfs, fdisk, parted, dd, rm -r immer lsblk, und das Laufwerk an der Größe erkennen.

48.7 Texteditor-Fallen

  • nano: Speichern Strg+O, Enter, beenden Strg+X. Nicht gespeichert = Änderung weg.
  • Tabs im Python-Quelltext: TabError; mit expand -t 4 datei > neu umwandeln.
  • Windows-Editor: erzeugt CRLF; siehe 48.1.
  • Datei lässt sich nicht speichern: Besitzer prüfen (48.2).
