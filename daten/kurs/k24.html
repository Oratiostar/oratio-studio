24.1 Was ist möglich?

Ein großes KI-Modell wie ein Online-Chatbot läuft nicht auf einem Pi. Ein kleiner lokaler Assistent schon. Die Kette:

Mikrofon hört  →  Sprache wird zu Text  →  KI verarbeitet  →  Antwort wird gesprochen

24.2 Die Bausteine

Aufgabe Programm
Lokale Sprach-KI Ollama mit einem kleinen Modell (zum Beispiel qwen2.5:0.5b)
Sprache zu Text Whisper oder Vosk
Text zu Sprache Piper (schnell und komplett lokal)
Wake-Word (der Rufname) Porcupine (hier der ursprüngliche Plan; im Control Center übernimmt die Erkennung später Vosk mit dem eingestellten Namen, Kapitel 39.3)

24.3 Hardware

Pflicht: Raspberry Pi 4 (4 oder 8 GB) oder Pi 5, microSD 32 GB oder mehr, Netzteil 5 V / 3 A, Lüfter, USB-Mikrofon (oder ReSpeaker 2-Mic HAT), Lautsprecher, WLAN. Optional: Bildschirm, LED-Matrix, ESP32, Relais, Sensoren.

24.4 Schritt für Schritt

1. Pi vorbereiten

sudo apt update
sudo apt upgrade -y
sudo apt install -y git curl python3 python3-venv python3-pip portaudio19-dev espeak alsa-utils

2. Mikrofon und Lautsprecher testen

arecord -l
speaker-test -t wav

3. Ollama installieren und ein kleines Modell laden

curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:0.5b
ollama run qwen2.5:0.5b

Dann „Hallo, wer bist du?" eintippen. Antwortet es, läuft die lokale KI.

4. Erstes Programm mit eigenem Namen (nur Text, noch ohne Stimme)

nano oratio_ai.py
import subprocess

name = "Oratio AI"

while True:
    frage = input("Du: ")

    if frage.lower() in ["exit", "quit", "ende"]:
        break

    prompt = f"Du bist {name}. Antworte kurz, freundlich und auf Deutsch. Frage: {frage}"

    antwort = subprocess.check_output(
        ["ollama", "run", "qwen2.5:0.5b", prompt],
        text=True
    )

    print(f"{name}: {antwort}")
python3 oratio_ai.py

5. Als Nächstes Mikrofon und gesprochene Antwort (Whisper/Vosk + Piper), dann das Wake-Word.

24.5 Namen und Sprache

Für den Namen des Assistenten habe ich Ideen gesammelt, zum Beispiel ORAI (ORAtio + AI), Oris, OraMind, OraNova. Eine eigene Sprache (zum Beispiel die Muttersprache) lässt sich so unterstützen, dass man Beispielsätze und Schlüsselwörter sammelt und sie Aktionen zuordnet („Licht an", „Fernseher aus"). Der Assistent muss die Sprache nicht offiziell können, wenn die Befehlsliste selbst gepflegt wird.

24.6 Wie viele Befehle kann der Pi steuern?

Meine Frage war: „Ich habe tausende Befehle, aber mein GPIO hat nicht so viele Anschlüsse." Kurz gesagt: Die Befehle liegen in Software (Liste oder Datenbank). Die Pins werden nur für die Dinge gebraucht, die wirklich geschaltet werden. Mehr Ausgänge bekommt man über Erweiterungen (zum Beispiel I²C-Portexpander) oder indem man einen ESP32 als Helfer daran hängt.
