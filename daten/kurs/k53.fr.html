Voici comment ce lexique est construit : chaque message est en gras, en dessous signification, cause et solution. Avec la fonction de recherche du lecteur PDF, on peut chercher une partie du message. Les messages sont classés par thème (chapitres 53 à 58).

La règle de base : lire le message de bas en haut. La dernière ligne nomme le plus souvent la vraie cause, les lignes avant montrent où cela s'est produit.

53.1 Commande introuvable

bash: xyz: Kommando nicht gefunden / command not found

Signification : le shell ne connaît pas la commande xyz.

Causes et solutions possibles :

Cause Vérifier Solution
Faute de frappe (la casse compte) Retaper exactement la commande corriger
Programme non installé which xyz n'affiche rien sudo apt install xyz
Programme seulement dans un environnement propre par exemple pio (PlatformIO) ou code utiliser le chemin complet, par exemple ~/.platformio/penv/bin/platformio, ou installer VS Code
La commande appartient à un autre système sudo: pacman: command not found sur le Pi, sudo: apt: command not found sur le Steam Deck sur le Raspberry Pi on utilise apt, sur le Steam Deck (SteamOS, base Arch) pacman
Le programme de panneau/bureau n'existe pas dans cette version par exemple lxpanelctl: command not found sur le nouveau Raspberry Pi OS avec labwc se déconnecter et se reconnecter au lieu de redémarrer le panneau
Programme dans le dossier courant ./programm au lieu de programm indiquer le chemin avec ./ devant

curl: command not found

sudo apt install curl. Puis répéter la commande.

Fehler: Paket powershell kann nicht gefunden werden

apt ne connaît pas le paquet, car PowerShell ne se trouve pas dans les sources de paquets standard. Soit configurer la source de paquets de Microsoft, soit ne pas installer PowerShell sur le Pi. La plupart des tâches se résolvent sous Linux avec bash.

Zeile 1: from: Kommando nicht gefunden (ligne 2, ligne 3 ...)

Signification : un fichier Python a été lancé comme un script shell. Le shell lit from ... import ... comme la commande from et ne la connaît pas.

Solution : toujours lancer les fichiers Python avec l'interpréteur :

python3 datei.py

Si le fichier doit tourner directement avec ./datei.py, il lui faut en première ligne #!/usr/bin/env python3 et chmod +x datei.py.

bad interpreter: /bin/bash^M

Cause : le fichier a été enregistré sous Windows et a des fins de ligne Windows (CRLF).

Solution :

sed -i 's/\r$//' script.sh

53.2 Droits et fichiers

Permission denied / Keine Berechtigung

Signification : l'utilisateur n'a pas le droit de lire, d'écrire ou d'exécuter le fichier ou le dossier.

Marche à suivre :

  1. Regarder les droits : ls -l datei
  2. Changer le propriétaire et les droits, selon le cas :
chmod +x script.sh            # ausführbar machen (Zeile ./script.sh Permission denied)
sudo chown oratio:oratio datei  # Besitzer ändern
sudo chmod -R 755 ordner        # Ordner lesbar und betretbar (siehe 2.10)
  1. N'utiliser sudo que si nécessaire. Sur des partitions de données appartenant à un autre système (par exemple Batocera SHARE), sudo chmod -R 777 /media/oratio/SHARE donne les droits d'écriture (chapitre 26.6).

bash: ./script.sh: Permission denied

Le script n'est pas exécutable : chmod +x script.sh, puis ./script.sh.

No such file or directory / Datei oder Verzeichnis nicht gefunden

Signification : le chemin n'est pas correct.

Vérifier : pwd (où suis-je ?), ls (qu'y a-t-il ici ?), majuscules/minuscules, espaces (mettre entre guillemets les chemins avec espaces), tilde ~ seulement au début d'un chemin.

Important : si devant une commande se trouve un <, le shell essaie de lire le fichier comme entrée (<wlr-randr ... mène à « fichier introuvable »). Saisir la commande sans le <.

ls: cannot access '/dev/ttyUSB*': No such file or directory

Aucun appareil USB-série n'est reconnu. Voir le chapitre 55.4 (carte non reconnue).

53.3 Programmes et paquets

E: Unable to locate package ...

Exécuter sudo apt update, vérifier le nom (apt search name).

error: externally-managed-environment (avec pip install)

Le nouveau Raspberry Pi OS n'autorise pas pip dans le système. Solution : utiliser un environnement virtuel (chapitre 3) :

python3 -m venv ~/.venvs/projekt
source ~/.venvs/projekt/bin/activate
pip install paket

ModuleNotFoundError: No module named 'xyz'

Le paquet Python manque dans l'environnement utilisé. Vérifier que le bon environnement est actif (source .../activate), puis pip install xyz. Si le programme est lancé avec sudo, il ne voit pas l'environnement : utiliser sudo -E ou le chemin complet du programme Python de l'environnement (typique pour No module named 'rgbmatrix', voir 33.6).

cannot execute binary file: Exec format error

Signification : le programme est construit pour une autre architecture de processeur. Typique : un fichier amd64 (Steam Deck, PC) sur le Raspberry Pi ARM64.

Solution : utiliser la version adaptée à ARM64 ou installer le programme depuis la source de paquets (sudo apt install rpi-imager). Vérifier l'architecture : uname -m (aarch64 = ARM64, x86_64 = amd64).

53.4 Particularités du terminal

  • ^[[A apparaît au lieu de la flèche : le shell ne connaît pas l'édition de ligne (par exemple dans sh au lieu de bash). Lancer avec bash.
  • unexpected end of file dans un script : il manque une parenthèse, un if sans fi ou un do sans done.
  • La commande reste bloquée : Ctrl+C interrompt. Un programme en arrière-plan se termine avec kill PID (PID via ps aux | grep name).
